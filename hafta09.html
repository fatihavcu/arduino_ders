1Haftanın Hedefleri

  • Solma etkisi (fade) programını hem değişken adımla hem de for döngüleriyle yazabilmek

Bu hafta 6. ve 7. haftalarda öğrendiğimiz analog okuma (analogRead) ile bugünkü analog yazmayı (analogWrite) birleştiriyoruz: sensörden oku → ölçekle → PWM ile yaz.

2Analog Çıkış Problemi ve PWM

Dijital bir pin yalnızca iki gerilim üretebilir: HIGH = 5 V veya LOW = 0 V. Peki LED'i yarı parlaklıkta yakmak ya da bir motoru yavaş döndürmek için 2,5 V gibi ara bir değere ihtiyaç duyarsak ne olur? Arduino UNO'daki ATmega328P'de gerçek bir DAC (Dijital-Analog Çevirici) yoktur. Bunun yerine PWM (Pulse Width Modulation – Darbe Genişlik Modülasyonu) tekniği kullanılır.

PWM'de pin, saniyede yüzlerce kez çok hızlı biçimde açılıp kapanır. Bir periyot içinde pinin HIGH kaldığı süre oranı değiştirilerek yüke aktarılan ortalama güç ayarlanır. LED gibi yükler ve insan gözü bu hızlı değişimi takip edemez; göz yalnızca ortalama parlaklığı algılar (görme sürekliliği).

Şekil 1. DAC sabit ara gerilim üretir; PWM ise 0/5 V arasında hızla anahtarlayarak aynı ortalamayı sağlar.

PWM nerelerde kullanılır?

  • LED parlaklık kontrolü (bu hafta)
  • DC motor hız kontrolü (motor sürücü ile)
  • Servo motor konum kontrolü (12. hafta – farklı bir darbe protokolü)
  • Buzzer/hoparlörle ses üretimi (tone())
  • RC filtre ile gerçek analog gerilim elde etme
PWM çıkışını bir RC alçak geçiren filtreden (örn. 10 kΩ + 10 µF) geçirirseniz, multimetrede gerçekten ortalama gerilime yakın sabit bir değer ölçersiniz.

3Görev Döngüsü (Duty Cycle) ve Ortalama Gerilim

Bir PWM sinyalinde bir tam açma-kapama süresine periyot (T), saniyedeki periyot sayısına frekans (f) denir. Pinin HIGH kaldığı süre ton, LOW kaldığı süre toff'tur.

T = 1 / f   ·   D = ton / T × %100   ·   Vort = D × 5 V

Arduino'da görev döngüsü 8 bitlik bir değerle (0–255) verilir. Dolayısıyla analogWrite(pin, x) için:

D = x / 255   ⟹   Vort = 5 V × x / 255
analogWrite değeriGörev döngüsüOrtalama gerilimLED
0%00 VSönük
64≈ %25≈ 1,25 VLoş
127≈ %50≈ 2,49 VOrta
191≈ %75≈ 3,75 VParlak
255%1005 VTam parlak

Çözümlü örnek: 9. pinde (f ≈ 490 Hz) analogWrite(9, 51) yazılırsa: T = 1/490 ≈ 2,04 ms; D = 51/255 = %20; ton = 0,2 × 2,04 ≈ 0,41 ms; Vort = 0,2 × 5 = 1 V.

4analogWrite() ve PWM Pinleri

analogWrite(pin, değer) fonksiyonu seçilen pinde, değer/255 görev döngüsüne sahip bir PWM sinyali başlatır. Sinyal, başka bir analogWrite, digitalWrite veya digitalRead çağrılana kadar arka planda (zamanlayıcı donanımı tarafından) kesintisiz üretilir; delay() sırasında da devam eder.

Şekil 2. Arduino UNO dijital pin başlığı: yalnızca ~ işaretli 6 pin PWM üretebilir.

5, 6Timer0≈ 980 Hz (976,6 Hz)millis() ve delay() de Timer0'ı kullanır

Önemli kurallar

  • Değer aralığı 0–255'tir (8 bit). analogRead ise 0–1023 (10 bit) döndürür; doğrudan aktarılamaz.
  • analogWrite(pin, 0) pini sürekli LOW, analogWrite(pin, 255) sürekli HIGH yapar.
  • Analog giriş pinleri (A0–A5) PWM çıkışı veremez; "analog" adına rağmen analogWrite için kullanılmaz.
  • PWM olmayan bir pine (örn. 7) analogWrite yazılırsa pin 128'den küçük değerlerde LOW, 128 ve üzerinde HIGH olur; ara parlaklık elde edilmez.

Kod karşılaştırması

dogru_yanlis.ino
analogWrite(9, 128);   // ✓ ~%50 parlaklık
analogWrite(7, 128);   // ✗ 7 PWM değil: LED tam yanar
analogWrite(A0, 100);  // ✗ A0 PWM çıkışı veremez
analogWrite(10, analogRead(A0));      // ✗ 0–1023 > 255
analogWrite(10, analogRead(A0) / 4);  // ✓ 0–255
PWM pini de olsa her pin en fazla 20 mA (mutlak sınır 40 mA) verebilir. LED'i mutlaka seri dirençle (≈ 220 Ω) bağlayın; motor gibi yüksek akımlı yükler için transistör veya motor sürücü kullanın.

5Uygulama 1: Solma Etkisi (Fade)

LED'in parlaklığını yavaşça artırıp azaltan bu program, Arduino IDE'deki Dosya → Örnekler → 01.Basics → Fade örneğinin açıklamalı hâlidir. Devre: D9 → LED anot, LED katot → 220 Ω → GND (Şekil 3'teki devrenin LED kısmı).

Fade.ino
// Solma etkisi (Fade): 9 numaralı PWM pinindeki LED yavaşça yanar ve söner
const int ledPin = 9;      // ~9 : PWM destekli pin
int parlaklik = 0;         // o anki PWM değeri (0–255)
int adim = 5;              // her döngüde parlaklığın değişim miktarı

void setup() {
  pinMode(ledPin, OUTPUT); // (analogWrite bunu kendisi de yapar, yazmak iyi alışkanlıktır)
  Serial.begin(9600);      // değerleri Seri Monitör / Seri Çizici'de izlemek için
}

void loop() {
  analogWrite(ledPin, parlaklik);   // görev döngüsü = parlaklik / 255
  Serial.println(parlaklik);

  parlaklik = parlaklik + adim;     // bir sonraki değer
  // Uçlara ulaşınca yönü tersine çevir
  if (parlaklik <= 0 || parlaklik >= 255) {
    adim = -adim;
  }
  delay(30);                        // 30 ms bekle -> solma hızı
}

🔬 Simülasyon 2: Fade programını çalıştırın

Adım değeri 255'i tam bölmüyorsa (örn. 7) parlaklık 252 → 259 olur ve 255'i aşar. analogWrite'a 255'ten büyük bir değer yazmak beklenmedik sonuç verir (değer 8 bitlik yazmaca sığmaz). Güvenli yazım: if (parlaklik >= 255) { parlaklik = 255; adim = -adim; } veya constrain() kullanmak.

Aynı etki for döngüleriyle

Fade_for.ino
// Solma etkisinin for döngüleri ile yazılmış hâli
const int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // 0'dan 255'e: yavaşça aydınlan
  for (int deger = 0; deger <= 255; deger++) {
    analogWrite(ledPin, deger);
    delay(8);               // 256 adım x 8 ms ≈ 2 saniye
  }
  // 255'ten 0'a: yavaşça kararan LED
  for (int deger = 255; deger >= 0; deger--) {
    analogWrite(ledPin, deger);
    delay(8);
  }
  delay(500);               // tamamen sönükken yarım saniye bekle
}

Bu sürümde LED, 256 adımda yaklaşık 256 × 8 ms ≈ 2 s'de aydınlanır ve yine 2 s'de söner. 5. haftada öğrendiğimiz for döngüsünün sayacı doğrudan PWM değeri olarak kullanılmıştır.

6map() Fonksiyonu: Aralık Dönüştürme

analogRead() 10 bitlik ADC kullanır ve 0–1023 döndürür; analogWrite() ise 8 bitlik 0–255 değer bekler. Bir aralıktaki sayıyı başka bir aralığa doğrusal olarak taşımak için map() kullanılır:

map(x, amin, amax, bmin, bmax) = (x − amin) · (bmax − bmin) / (amax − amin) + bmin

Örnek 1: map(512, 0, 1023, 0, 255) = 512 · 255 / 1023 = 127,6 → 127

Örnek 2 (ters): map(200, 0, 1023, 255, 0) = 200 · (−255) / 1023 + 255 = −49,8 → −49 + 255 = 206

Örnek 3: map(700, 0, 1023, 0, 100) → 68 (yüzde olarak)

  • map() tam sayı (long) aritmetiği kullanır; ondalık kısım kesilir (yuvarlanmaz).
  • Sonucu aralıkla sınırlamaz: map(1200, 0, 1023, 0, 255) = 299 olur. Sınırlamak için constrain(x, alt, üst) kullanılır.
  • Hedef aralık ters yazılırsa (255, 0) eşleme ters orantılı olur.
  • Pratik kısa yol: analogRead(A0) / 4 da 0–255 verir (1023/4 = 255).

7Uygulama 2: Potansiyometre ile LED Parlaklığı

7. haftada potansiyometreyi bir ayarlı gerilim bölücü olarak kullanmıştık: dış uçlar 5 V ve GND'ye, orta uç (silecek) A0'a bağlanır. Bu hafta okunan değeri PWM'e çevirip LED'i süreceğiz.

Şekil 3. Potansiyometre (A0) ve LED (D9 + 220 Ω) devresi. Aşağıdaki kaydırıcı devreyi canlı olarak çalıştırır.
Pot_LED.ino
// Potansiyometre ile LED parlaklığı kontrolü
const int potPin = A0;     // potansiyometrenin orta ucu (silecek)
const int ledPin = 9;      // LED + 220 Ω, PWM pini

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int potDeger = analogRead(potPin);              // 0–1023 (10 bit ADC)
  int pwm = map(potDeger, 0, 1023, 0, 255);       // 0–255 (8 bit PWM)
  analogWrite(ledPin, pwm);

  float gerilim = potDeger * 5.0 / 1023.0;        // pot ucundaki gerilim (yaklaşık)
  Serial.print("Pot: ");
  Serial.print(potDeger);
  Serial.print("  Gerilim: ");
  Serial.print(gerilim, 2);
  Serial.print(" V  PWM: ");
  Serial.println(pwm);
  delay(200);
}

🔬 Simülasyon 3: Potansiyometreyi çevirin

Hesaplamada 1023'e bölmek (5,0/1023,0) potun en uç konumunda tam 5,00 V gösterir; ADC'nin tanımına göre teorik olarak doğru bölen 1024'tür. İki yöntem arasındaki fark yaklaşık %0,1'dir ve bu uygulama için önemsizdir.

8Uygulama 3: LDR ile Ters Orantılı Parlaklık (Gece Lambası)

LDR (fotodirenç) üzerine düşen ışık arttıkça direnci azalır (aydınlıkta ≈ birkaç yüz Ω – birkaç kΩ, karanlıkta yüzlerce kΩ – MΩ). LDR'yi 10 kΩ ile gerilim bölücü yaparız:

VA0 = 5 V · Rsabit / (RLDR + Rsabit)    (5V – LDR – A0 – 10 kΩ – GND)

Bu bağlantıda ışık arttıkça VA0 artar. Gece lambasında ise karanlıkta LED parlak olmalıdır; bu yüzden map() hedef aralığı ters yazılır (255, 0). Ayrıca LDR hiçbir zaman tam 0 veya 1023 vermediğinden, gerçek ortamda ölçtüğünüz uç değerler kalibrasyon sabitleri olarak kullanılır ve constrain() ile sınırlanır.

GeceLambasi.ino
// Gece lambası: ortam karardıkça LED daha parlak yanar (ters orantı)
// Bağlantı: 5V -- LDR -- A0 -- 10 kΩ -- GND  (ışık arttıkça A0 gerilimi artar)
const int ldrPin = A0;
const int ledPin = 9;
const int KARANLIK = 150;  // karanlık ortamda okunan değer (kendi ortamınızda ölçün)
const int AYDINLIK = 900;  // aydınlık ortamda okunan değer (kendi ortamınızda ölçün)

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int isik = analogRead(ldrPin);                       // 0–1023
  int sinirli = constrain(isik, KARANLIK, AYDINLIK);    // aralık dışına taşmayı engelle
  int parlaklik = map(sinirli, KARANLIK, AYDINLIK, 255, 0); // TERS eşleme
  analogWrite(ledPin, parlaklik);

  Serial.print("LDR: ");
  Serial.print(isik);
  Serial.print("  PWM: ");
  Serial.println(parlaklik);
  delay(100);
}

🔬 Simülasyon 4: Ortam ışığını değiştirin

Kalibrasyon için önce yalnızca Serial.println(analogRead(A0)); yazan bir program yükleyin; LDR'yi elinizle kapatıp (KARANLIK) fenere tutarak (AYDINLIK) değerleri not edin.

9Uygulama 4: RGB LED ile Renk Karışımı

RGB LED, tek bir kılıf içinde kırmızı (R), yeşil (G) ve mavi (B) üç LED barındırır ve 4 bacaklıdır. En uzun bacak ortak uçtur:

  • Ortak katot (en yaygını): ortak bacak GND'ye bağlanır; renk bacağına yüksek PWM değeri = parlak renk.
  • Ortak anot: ortak bacak 5 V'a bağlanır; mantık terstir, 0 = tam parlak, 255 = sönük (255 − değer yazılır).

Üç rengin PWM değerleri ayrı ayrı ayarlanarak toplamsal renk karışımı ile (her biri 256 seviye) 256³ ≈ 16,7 milyon renk tonu elde edilebilir. Her renk bacağına ayrı bir ≈ 220 Ω direnç bağlanmalıdır.

RGB_Renkler.ino
// Ortak katotlu RGB LED ile renk karışımı
const int kirmiziPin = 9;    // R bacağı -> 220 Ω -> ~9
const int yesilPin   = 10;   // G bacağı -> 220 Ω -> ~10
const int maviPin    = 11;   // B bacağı -> 220 Ω -> ~11
// En uzun bacak (ortak katot) -> GND

// Üç rengi tek seferde ayarlayan yardımcı fonksiyon
void renkAyarla(int r, int g, int b) {
  analogWrite(kirmiziPin, r);
  analogWrite(yesilPin, g);
  analogWrite(maviPin, b);
  // Ortak ANOTLU LED kullanıyorsanız: analogWrite(kirmiziPin, 255 - r); ...
}

void setup() {
  pinMode(kirmiziPin, OUTPUT);
  pinMode(yesilPin, OUTPUT);
  pinMode(maviPin, OUTPUT);
}

void loop() {
  renkAyarla(255, 0, 0);     delay(1000);  // kırmızı
  renkAyarla(0, 255, 0);     delay(1000);  // yeşil
  renkAyarla(0, 0, 255);     delay(1000);  // mavi
  renkAyarla(255, 255, 0);   delay(1000);  // sarı   = kırmızı + yeşil
  renkAyarla(0, 255, 255);   delay(1000);  // camgöbeği = yeşil + mavi
  renkAyarla(255, 0, 255);   delay(1000);  // mor (eflatun) = kırmızı + mavi
  renkAyarla(255, 80, 0);    delay(1000);  // turuncu
  renkAyarla(255, 255, 255); delay(1000);  // beyaz
}

11Kendini Test Et

1) analogWrite(6, 64); komutunun görev döngüsü ve ortalama gerilimi yaklaşık nedir?

✓ D = 64/255 ≈ 0,25 → Vort = 0,25 × 5 V ≈ 1,25 V.

2) Arduino UNO'da aşağıdaki pinlerden hangisi PWM çıkışı veremez?

✓ UNO'da PWM pinleri yalnızca 3, 5, 6, 9, 10, 11'dir. 7 numaralı pin sadece HIGH/LOW verebilir.

3) map(512, 0, 1023, 0, 255) ifadesinin sonucu nedir?

✓ 512·255/1023 = 127,6; map() tam sayı aritmetiği kullandığı için ondalık kısım kesilir → 127.

4) Ortak anotlu bir RGB LED'in kırmızı rengini TAM parlak yakmak için kırmızı pine hangi değer yazılmalıdır?

✓ Ortak anotta ortak uç 5 V'tadır; akım, renk pini LOW olduğunda akar. Bu yüzden 0 = tam parlak, 255 = sönüktür.

5) analogWrite(10, analogRead(A0)); satırının sorunu nedir?

✓ 10 bitlik okuma 8 bitlik yazmaya sığmaz; 255'ten büyük değerler beklenmedik parlaklık üretir. Doğrusu: analogWrite(10, map(analogRead(A0), 0, 1023, 0, 255));

12Ödev ve Özet

Ödev

  1. Nefes alan LED: Fade programını, LED tamamen sönükken 1 s, tamamen parlakken 0,5 s bekleyecek şekilde düzenleyin.
  2. Hız ayarlı solma: Potansiyometreyi A0'a bağlayın; pot değeri ile delay süresini 2–50 ms arasında ayarlayan bir Fade programı yazın (map kullanın).
  3. Renk geçişi: RGB LED'in rengini kırmızı → yeşil → mavi → kırmızı şeklinde yumuşak geçişlerle (for döngüleriyle) değiştirin.
  4. Hesap: 5. pinde analogWrite(5, 200) için frekans, periyot, ton, toff ve ortalama gerilimi hesaplayın.
2. ödev için ipucu (tıklayın)
hizli_fade_ipucu.ino
int parlaklik = 0, adim = 5;

void setup() { pinMode(9, OUTPUT); }

void loop() {
  int bekleme = map(analogRead(A0), 0, 1023, 2, 50);  // 2–50 ms
  analogWrite(9, parlaklik);
  parlaklik += adim;
  if (parlaklik <= 0 || parlaklik >= 255) adim = -adim;
  delay(bekleme);
}

Özet

  • UNO'da gerçek DAC yoktur; ara gerilim etkisi PWM ile elde edilir: Vort = 5 V × değer / 255.
  • analogWrite(pin, 0–255) yalnızca 3, 5, 6, 9, 10, 11 pinlerinde çalışır (5, 6: ≈980 Hz; diğerleri ≈490 Hz).
  • Solma etkisi, PWM değerinin küçük adımlarla artırılıp azaltılmasıyla yapılır; adım uçları aşmamalıdır.
  • map() aralık dönüştürür (tam sayı, sınırsız); constrain() sınırlar. Ters eşleme: map(x, 0, 1023, 255, 0).
  • RGB LED'de üç PWM kanalı ile renk karıştırılır; ortak anotta değerler ters çevrilir (255 − değer).
