2Dijital Sinyal ve Çıkış Pinleri

Dijital bir sinyal yalnızca iki değer alabilir: HIGH (1) ve LOW (0). Arduino UNO 5 V ile çalıştığından bir çıkış pini HIGH yapıldığında pinde ≈ 5 V, LOW yapıldığında ≈ 0 V bulunur.

Şekil 1. Blink programının pin gerilimi: 1 s HIGH, 1 s LOW (kare dalga). Kırmızı çizgi zamanı tarar.

Akım kaynağı ve akım yutucu

Bir LED pine iki şekilde bağlanabilir:

  • (a) Kaynak (source): pin → direnç → LED → GND. Pin HIGH olunca LED yanar. Bu derste kullanacağımız bağlantı budur.
  • (b) Yutucu (sink): 5V → direnç → LED → pin. Pin LOW olunca LED yanar (ters mantık).
Bir G/Ç pininden en fazla 20 mA çekilmesi önerilir (mutlak sınır 40 mA). Tüm pinlerin toplam akımı da ≈ 200 mA'i geçmemelidir. LED'i asla dirençsiz olarak pine bağlamayın.

5Karşılaştırma ve Mantık Operatörleri

Karşılaştırma (sonuç: true / false)

OperatörAnlamıÖrnek (x = 5)
==eşit mix == 5 → true
!=eşit değil mix != 5 → false
< / >küçük / büyükx < 3 → false
<= / >=küçük-eşit / büyük-eşitx >= 5 → true

Mantık

OperatörAnlamıÖrnek (x = 5)
&&VE: ikisi de doğruysax > 3 && x < 7 → true
||VEYA: en az biri doğruysax < 3 || x == 5 → true
!DEĞİL: tersine çevirir!(x == 5) → false

Aritmetik ve atama operatörleri

+ − * / dört işlem; % bölümden kalan (7 % 3 = 1; bir sayının çift olup olmadığı x % 2 == 0 ile anlaşılır); x++ bir artırır, x-- bir azaltır; x += 5 ⟺ x = x + 5.

= atama, == karşılaştırmadır. if (sayac = 5) yazarsanız sayaca 5 atanır ve koşul her zaman doğru olur; derleyici hata vermez! Doğrusu: if (sayac == 5).

6if – else if – else Yapısı

if-else şablonu (genel yazım)
if (koşul1) {
  // koşul1 doğruysa çalışır
} else if (koşul2) {
  // koşul1 yanlış, koşul2 doğruysa çalışır
} else {
  // hiçbiri doğru değilse çalışır
}

Koşullar yukarıdan aşağıya denenir; ilk doğru olan bloğun içi çalışır ve geri kalanlar atlanır. else if ve else kısımları isteğe bağlıdır. Blokta tek komut varsa süslü parantez yazılmayabilir, ancak hataları önlemek için her zaman yazmanız önerilir.

7Uygulama 1 ve 2: Harici LED ve Sırayla Yanan İki LED

Pin 8'e kırmızı, pin 9'a yeşil LED bağlıyoruz (her biri kendi 220 Ω direnciyle GND rayına). Uygulama 1 yalnızca pin 8'i kullanır; Uygulama 2 iki LED'i sırayla yakar.

🔬 Simülasyon: Devre şeması ve program birlikte çalışıyor

harici_blink.ino
// Uygulama 1: Pin 8'e bağlı harici LED'i yakıp söndürme
const int LED_PIN = 8;       // LED'in bağlı olduğu dijital pin
int beklemeSuresi = 500;     // milisaniye cinsinden bekleme

void setup() {
  pinMode(LED_PIN, OUTPUT);  // Pin 8'i çıkış yap
}

void loop() {
  digitalWrite(LED_PIN, HIGH);   // Pine 5 V ver: LED yanar
  delay(beklemeSuresi);
  digitalWrite(LED_PIN, LOW);    // Pini 0 V yap: LED söner
  delay(beklemeSuresi);
}
sirali_iki_led.ino
// Uygulama 2: İki LED'in sırayla (dönüşümlü) yanması
const int LED1 = 8;
const int LED2 = 9;
bool sira = true;            // true: LED1'in sırası, false: LED2'nin

void setup() {
  pinMode(LED1, OUTPUT);
  pinMode(LED2, OUTPUT);
}

void loop() {
  if (sira) {                    // sira == true ise
    digitalWrite(LED1, HIGH);
    digitalWrite(LED2, LOW);
  } else {                       // sira == false ise
    digitalWrite(LED1, LOW);
    digitalWrite(LED2, HIGH);
  }
  sira = !sira;                  // Sırayı tersine çevir
  delay(500);
}
if (sira) yazmak if (sira == true) ile aynıdır. sira = !sira; satırı her döngüde değişkeni true ↔ false arasında değiştirir; bu kalıba toggle (aç-kapa) denir ve 4. haftada butonla birlikte tekrar kullanacağız.

8Uygulama 3: Trafik Lambası

Kırmızı LED pin 12'ye, sarı LED pin 11'e, yeşil LED pin 10'a bağlanır. Türkiye'deki taşıt lambalarına benzer şekilde sıra kırmızı → kırmızı+sarı → yeşil → sarı → kırmızı biçimindedir.

Şekil 4. Trafik lambası devresi: üç LED, üç 220 Ω direnç, ortak GND
trafik_lambasi.ino
// Uygulama 3: Trafik lambası
const int KIRMIZI = 12;
const int SARI    = 11;
const int YESIL   = 10;

// Üç lambanın durumunu tek satırda ayarlayan yardımcı fonksiyon
void lambalar(int k, int s, int y) {
  digitalWrite(KIRMIZI, k);
  digitalWrite(SARI, s);
  digitalWrite(YESIL, y);
}

void setup() {
  pinMode(KIRMIZI, OUTPUT);
  pinMode(SARI, OUTPUT);
  pinMode(YESIL, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  lambalar(HIGH, LOW, LOW);   Serial.println("KIRMIZI");      delay(5000);
  lambalar(HIGH, HIGH, LOW);  Serial.println("KIRMIZI+SARI"); delay(2000);
  lambalar(LOW, LOW, HIGH);   Serial.println("YESIL");        delay(5000);
  lambalar(LOW, HIGH, LOW);   Serial.println("SARI");         delay(2000);
}

9Uygulama 4: Sayaca Göre LED (if – else if – else)

Aynı trafik lambası devresini kullanıyoruz. Bir sayaç her saniye 1 artar ve 0–9 arasında döner. Sayacın değerine göre: 0–2 → yeşil, 3–6 → sarı, 7–9 → kırmızı LED yanar. Ayrıca sayaç çift ise kart üzerindeki L LED'i (pin 13) yanar.

sayac_led.ino
// Uygulama 4: Sayaç değerine göre LED seçimi
const int YESIL = 10, SARI = 11, KIRMIZI = 12;
int sayac = 0;                       // 0..9 arası döner

void setup() {
  pinMode(YESIL, OUTPUT);
  pinMode(SARI, OUTPUT);
  pinMode(KIRMIZI, OUTPUT);
  pinMode(LED_BUILTIN, OUTPUT);      // Pin 13 (L LED'i)
  Serial.begin(9600);
}

void loop() {
  // Önce bütün LED'leri söndür
  digitalWrite(YESIL, LOW);
  digitalWrite(SARI, LOW);
  digitalWrite(KIRMIZI, LOW);

  if (sayac < 3) {                   // 0, 1, 2
    digitalWrite(YESIL, HIGH);
  } else if (sayac <= 6) {           // 3, 4, 5, 6
    digitalWrite(SARI, HIGH);
  } else {                           // 7, 8, 9
    digitalWrite(KIRMIZI, HIGH);
  }

  if (sayac % 2 == 0) {              // Çift sayı mı?
    digitalWrite(LED_BUILTIN, HIGH);
  } else {
    digitalWrite(LED_BUILTIN, LOW);
  }

  Serial.print("sayac = ");
  Serial.println(sayac);

  sayac++;                           // Bir artır
  if (sayac > 9) {                   // 9'u geçtiyse başa dön
    sayac = 0;
  }
  delay(1000);
}

else if (sayac <= 6) → SARI
else → KIRMIZI
if (sayac % 2 == 0) → L yanar

10delay() Yerine millis(): Beklemesiz Zamanlama

delay() çalışırken işlemci hiçbir şey yapamaz: 5 saniyelik bir delay(5000) sırasında basılan bir butonu fark etmez. millis() ise kart açıldığından beri geçen süreyi milisaniye olarak döndürür ve programı durdurmaz. Fikir şudur: "Son işlemden bu yana yeterli süre geçti mi? Geçtiyse işlemi yap, geçmediyse başka işlerine devam et."

if (millis() − öncekiZaman ≥ aralık) { öncekiZaman = millis(); işlemi yap; }
millis_iki_led.ino
// İki LED'i birbirinden bağımsız hızlarda, delay() kullanmadan yakıp söndürme
const int LED1 = 8, LED2 = 9;
const unsigned long ARALIK1 = 500;    // LED1: 500 ms'de bir durum değiştirir
const unsigned long ARALIK2 = 1300;   // LED2: 1300 ms'de bir durum değiştirir
unsigned long onceki1 = 0, onceki2 = 0;
bool durum1 = false, durum2 = false;

void setup() {
  pinMode(LED1, OUTPUT);
  pinMode(LED2, OUTPUT);
}

void loop() {
  unsigned long simdi = millis();     // Şu anki zaman (ms)

  if (simdi - onceki1 >= ARALIK1) {   // LED1'in zamanı geldi mi?
    onceki1 = simdi;
    durum1 = !durum1;
    digitalWrite(LED1, durum1);
  }
  if (simdi - onceki2 >= ARALIK2) {   // LED2'nin zamanı geldi mi?
    onceki2 = simdi;
    durum2 = !durum2;
    digitalWrite(LED2, durum2);
  }
  // Burada başka işler (buton okuma vb.) beklemeden yapılabilir
}

🔬 Simülasyon: millis_iki_led.ino

FonksiyonAçıklama
millis()Açılıştan beri geçen ms. Dönüş tipi unsigned long; ≈ 49,7 günde bir taşar ve sıfırdan başlar. simdi - onceki >= ARALIK biçimindeki çıkarma, taşma anında da doğru çalışır.
micros()Mikrosaniye cinsinden süre (≈ 70 dakikada taşar).

11Kendini Test Et

1) pinMode(8, OUTPUT); digitalWrite(8, HIGH); satırlarından sonra pin 8 ile GND arasında yaklaşık kaç volt ölçülür?

✓ Arduino UNO 5 V lojik ile çalışır; HIGH çıkış ≈ 5 V'tur (yük altında biraz düşebilir).

2) int x = 32767; x++; işleminden sonra UNO'da x'in değeri nedir?

✓ UNO'da int 16 bittir; en büyük değer 32767'dir. Bir artırılınca taşar ve en küçük değere (−32768) sarar.

3) if (sayac = 5) { … } satırındaki hata nedir?

✓ = sayaca 5 atar ve sonuç (5) sıfırdan farklı olduğundan koşul daima doğru olur. Karşılaştırma == ile yapılır.

4) x = 7 iken (x > 3 && x < 7) ifadesinin sonucu nedir?

✓ x > 3 doğru, ancak x < 7 yanlıştır (7, 7'den küçük değildir). VE (&&) için ikisinin de doğru olması gerekir.

5) millis() fonksiyonunun dönüş değerini saklamak için en uygun tip hangisidir?

✓ millis() unsigned long döndürür. int kullanılırsa 32,7 saniye sonra taşar ve zamanlama bozulur.

12Ödev ve Özet

Ödev

  1. Trafik lambasına bir yaya lambası ekleyin (pin 9: yaya kırmızı, pin 8: yaya yeşil). Taşıtlara kırmızı yanarken yayalara yeşil yansın, diğer durumlarda yaya kırmızısı yansın.
  2. Dört LED'i (pin 8–11) bir sira sayacı ve if – else if yapısı kullanarak soldan sağa sırayla yakın (her adımda yalnızca bir LED yansın). for döngüsünü 5. haftada göreceğiz; bu ödevi döngüsüz çözün.
  3. sayac_led.ino programını, sayaç 3'ün katı olduğunda (% kullanarak) tüm LED'leri yakacak şekilde değiştirin.
  4. Trafik lambası programını delay() kullanmadan, millis() ile yeniden yazın.
4. ödev için ipucu (tıklayın)

Lambanın hangi aşamada olduğunu bir durum değişkeninde tutun; süre dolunca bir sonraki duruma geçin:

trafik_millis_ipucu.ino
const int KIRMIZI = 12, SARI = 11, YESIL = 10;
int durum = 0;                    // 0: kırmızı, 1: kırmızı+sarı, 2: yeşil, 3: sarı
unsigned long oncekiZaman = 0;
unsigned long sure = 5000;        // İçinde bulunulan durumun süresi

void lambalar(int k, int s, int y) {
  digitalWrite(KIRMIZI, k); digitalWrite(SARI, s); digitalWrite(YESIL, y);
}

void setup() {
  pinMode(KIRMIZI, OUTPUT); pinMode(SARI, OUTPUT); pinMode(YESIL, OUTPUT);
  lambalar(HIGH, LOW, LOW);       // Kırmızı ile başla
}

void loop() {
  if (millis() - oncekiZaman >= sure) {
    oncekiZaman = millis();
    durum++;
    if (durum > 3) durum = 0;

    if (durum == 0)      { lambalar(HIGH, LOW, LOW);  sure = 5000; }
    else if (durum == 1) { lambalar(HIGH, HIGH, LOW); sure = 2000; }
    else if (durum == 2) { lambalar(LOW, LOW, HIGH);  sure = 5000; }
    else                 { lambalar(LOW, HIGH, LOW);  sure = 2000; }
  }
  // Program burada beklemez; ileride buton okuma buraya eklenebilir
}

Özet

  • pinMode(pin, OUTPUT) pini çıkış yapar; digitalWrite(pin, HIGH/LOW) pine 5 V / 0 V verir.
  • LED'ler her zaman seri dirençle bağlanır; pin başına ≤ 20 mA önerilir.
  • Veri tipinin aralığını aşan değişken taşar; zaman için unsigned long, ondalık için float kullanılır.
  • == karşılaştırma, = atamadır. && VE, || VEYA, ! DEĞİL.
  • if – else if – else zincirinde yalnızca ilk doğru koşulun bloğu çalışır.
  • delay() programı durdurur; millis() ile beklemeden zamanlama yapılır.
