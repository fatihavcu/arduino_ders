2Karakter LCD (HD44780) Tanıyalım

Arduino projelerinde en çok kullanılan ekran, 16 sütun × 2 satır karakter gösterebilen 16×2 LCD'dir. Ekranın arkasında HD44780 (veya uyumlu) bir denetleyici bulunur. Denetleyici, gönderilen karakter kodlarını kendi içindeki karakter tablosundan (CGROM) 5×8 noktalık desenlere çevirerek ekrana basar.

HD44780'in her satır için 40 karakterlik bir bellek alanı (DDRAM) vardır; ekranda bunun yalnızca 16'sı görünür. scrollDisplayLeft() bu 40 karakterlik pencereyi kaydırır. 16'dan uzun bir metin yazdığınızda karakterler görünmeyen 17–40. sütunlara gider; aşağıdaki simülasyonda deneyebilirsiniz.
LCD'nin karakter tablosunda ç, ğ, ı, ö, ş, ü gibi Türkçe harfler yoktur. Bu nedenle LCD'ye yazılan metinlerde "Sicaklik", "Dunya" gibi yazımlar kullanılır ya da harfler createChar() ile özel karakter olarak tanımlanır (Ödev 2).

// Paralel bağlantı (I2C modülü olmadan) – LiquidCrystal.h IDE ile birlikte gelir
#include <LiquidCrystal.h>

//                RS  E  D4 D5 D6 D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  lcd.begin(16, 2);          // 16 sütun, 2 satır
  lcd.print("Merhaba Dunya!");
}

4I²C Haberleşme ve PCF8574 LCD Modülü

I²C (Inter-Integrated Circuit), yalnızca iki hat ile birçok cihazın haberleşmesini sağlayan seri bir veri yoludur: SDA (veri) ve SCL (saat). Arduino master (yönetici) olarak, her cihaza kendine özgü 7 bitlik adresi ile seslenir. UNO'da SDA = A4, SCL = A5 pinleridir (R3 kartlarda AREF yanındaki SDA/SCL pinleri de aynı hatlardır).

Şekil 2. I²C veri yolu: tüm cihazlar aynı iki hatta (SDA veri, SCL saat) paralel bağlanır; master her cihaza 7 bitlik adresiyle seslenir.

LCD'nin arkasına lehimlenen PCF8574 tabanlı modül, I²C'den gelen baytı 8 paralel çıkışa çevirerek LCD'nin RS, E, D4–D7 ve arka ışık hatlarını sürer. Böylece LCD yalnızca 4 kabloyla (GND, VCC, SDA, SCL) bağlanır.

Modül yongasıVarsayılan adres

PCF8574AT0x3F
MPU6050 (AD0 = GND)0x68 (AD0 = 5V/3,3V: 0x69)
i2c_tarayici.ino
// I2C tarayıcı: hattaki cihazların adreslerini Seri Monitöre yazar
#include <Wire.h>

void setup() {
  Serial.begin(9600);
  Wire.begin();
  Serial.println("I2C taranıyor...");
  byte bulunan = 0;
  for (byte adres = 1; adres < 127; adres++) {
    Wire.beginTransmission(adres);
    if (Wire.endTransmission() == 0) {     // 0 = cihaz yanıt verdi (ACK)
      Serial.print("Cihaz bulundu: 0x");
      if (adres < 16) Serial.print("0");
      Serial.println(adres, HEX);
      bulunan++;
    }
  }
  if (bulunan == 0) Serial.println("Hiç cihaz bulunamadı. Kabloları kontrol edin.");
}

void loop() { }

7Uygulama 1: Merhaba Dünya ve Kayan Yazı

lcd_merhaba.ino
// Hafta 13 – Uygulama 1: I2C LCD'de Merhaba Dünya ve kayan yazı
#include <Wire.h>
#include <LiquidCrystal_I2C.h>   // Kütüphane Yöneticisi: "LiquidCrystal I2C" (Frank de Brabander)

LiquidCrystal_I2C lcd(0x27, 16, 2);   // adres, sütun, satır (çalışmazsa 0x3F deneyin)

void setup() {
  lcd.init();                 // LCD'yi başlat
  lcd.backlight();            // arka ışığı aç
  lcd.setCursor(0, 0);        // 0. sütun, 0. satır (sol üst)
  lcd.print("Merhaba Dunya!");
  lcd.setCursor(0, 1);        // 0. sütun, 1. satır (alt satır)
  lcd.print("Arduino UNO");
  delay(2000);
}

void loop() {
  lcd.scrollDisplayLeft();    // tüm ekran içeriğini bir sütun sola kaydır
  delay(400);
}

8Uygulama 2: Sıcaklığı LCD'de Gösterme

lcd_sicaklik.ino
// Hafta 13 – Uygulama 2: LM35 sıcaklığını LCD'de gösterme
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
const int lm35Pin = A0;

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Sicaklik:");          // LCD'de Türkçe karakter yoktur
}

void loop() {
  int ham = analogRead(lm35Pin);        // 0 – 1023
  float volt = ham * 5.0 / 1023.0;      // V
  float sicaklik = volt * 100.0;        // LM35: 10 mV/°C

  lcd.setCursor(0, 1);
  lcd.print(sicaklik, 1);               // 1 ondalık basamak
  lcd.print((char)223);                 // derece işareti (karakter kodu 223)
  lcd.print("C   ");                    // önceki uzun değerin artıklarını sil

  lcd.setCursor(10, 1);
  lcd.print(ham);                       // ham ADC değeri
  lcd.print("   ");
  delay(500);
}

🔬 LM35 + LCD simülasyonu

LM35'in çıkışı 10 mV/°C'dir: 25 °C'de 0,25 V. 5 V referansla 1 ADC adımı 4,9 mV ≈ 0,49 °C'ye karşılık gelir; bu yüzden gösterilen değer yaklaşık yarım derecelik adımlarla değişir. (char)223, HD44780 tablosunda derece işaretine benzeyen karakterin kodudur.
Sayı kısaldığında (ör. 100,0 → 99,5) eski son hane ekranda kalır. Bu yüzden sayıdan sonra birkaç boşluk yazmak, döngüde clear() kullanmaktan daha iyidir (titreme olmaz).

9İvme Sensörü: MPU6050

İvmeölçer (accelerometer), bir cismin maruz kaldığı ivmeyi ölçen sensördür. Birimi genellikle g'dir (1 g ≈ 9,81 m/s²). MPU6050, tek yonga üzerinde 3 eksenli ivmeölçer ve 3 eksenli jiroskop barındıran bir MEMS (mikro-elektromekanik sistem) sensörüdür; içindeki mikroskobik kütle ivmeyle yer değiştirir ve bu, kapasitans değişimi olarak ölçülür. Veriler 16 bit ADC ile sayısallaştırılıp I²C üzerinden okunur.

İvmeden eğim açısına

Sensör hareketsizken ölçtüğü tek ivme yerçekimidir. Kart eğildikçe 1 g'lik yerçekimi vektörü eksenlere farklı oranlarda dağılır. Roll açısı φ (X ekseni etrafında) ve pitch açısı θ (Y ekseni etrafında) için:

ax = −sin θ  ·  ay = sin φ · cos θ  ·  az = cos φ · cos θ
roll φ = atan2(ay, az)     pitch θ = atan2(−ax, √(ay² + az²))

atan2(y, x) fonksiyonu sonucu radyan olarak −π…+π aralığında verir; dereceye çevirmek için 180/π ile çarpılır. Ham değer g'ye ham / 16384 ile çevrilir (±2 g aralığında).

İvmeölçer yalnızca yerçekimine göre eğimi ölçer: yaw (Z ekseni etrafında, yatay düzlemde dönme) açısı ivmeden bulunamaz; bunun için jiroskop veya pusula (manyetometre) gerekir. Ayrıca sensör hareket halindeyken (sallanırken) ölçülen ivme yerçekimine eklenir ve açı hesabı bozulur. Pratikte ivmeölçer ile jiroskop tamamlayıcı filtre veya Kalman filtresiyle birleştirilir.
Kayıtları kendimiz okuyacağımız için ek kütüphane gerekmez. Dilerseniz Kütüphane Yöneticisi'nden "Adafruit MPU6050" (Adafruit Unified Sensor ve BusIO bağımlılıklarıyla birlikte) ya da "MPU6050" (Electronic Cats) kütüphanelerini kurabilirsiniz.

10Uygulama 3: Eğim Açılarını LCD'de Gösterme

mpu6050_egim_lcd.ino
// Hafta 13 – Uygulama 3: MPU6050 ile eğim açılarını LCD'de gösterme
// Ek kütüphane gerekmez: MPU6050 kayıtları Wire.h ile doğrudan okunur
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const int MPU = 0x68;                 // AD0 = LOW iken adres
LiquidCrystal_I2C lcd(0x27, 16, 2);

// I2C'den gelen iki baytı (yüksek, düşük) işaretli 16 bit sayıya çevirir
int16_t oku16() {
  uint8_t yuksek = Wire.read();
  uint8_t dusuk = Wire.read();
  return (int16_t)(((uint16_t)yuksek << 8) | dusuk);
}

void setup() {
  Serial.begin(9600);
  Wire.begin();
  Wire.beginTransmission(MPU);
  Wire.write(0x6B);                   // PWR_MGMT_1 kaydı
  Wire.write(0);                      // 0 yaz: uyku modundan çıkar
  Wire.endTransmission(true);
  // ACCEL_CONFIG varsayılanı ±2 g -> 16384 LSB/g
  lcd.init();
  lcd.backlight();
}

void loop() {
  Wire.beginTransmission(MPU);
  Wire.write(0x3B);                   // ACCEL_XOUT_H kaydından başla
  Wire.endTransmission(false);        // hattı bırakmadan yeniden başlat
  Wire.requestFrom(MPU, 6, true);     // 6 bayt: X, Y, Z (her biri H + L)
  int16_t axHam = oku16();
  int16_t ayHam = oku16();
  int16_t azHam = oku16();

  float ax = axHam / 16384.0;         // g cinsinden
  float ay = ayHam / 16384.0;
  float az = azHam / 16384.0;

  float roll  = atan2(ay, az) * 180.0 / PI;                     // X ekseni etrafında
  float pitch = atan2(-ax, sqrt(ay * ay + az * az)) * 180.0 / PI; // Y ekseni etrafında

  lcd.setCursor(0, 0);
  lcd.print("Pitch:");
  lcd.print(pitch, 1);
  lcd.print((char)223);
  lcd.print("    ");
  lcd.setCursor(0, 1);
  lcd.print("Roll :");
  lcd.print(roll, 1);
  lcd.print((char)223);
  lcd.print("    ");

  Serial.print("ax="); Serial.print(ax, 2);
  Serial.print(" ay="); Serial.print(ay, 2);
  Serial.print(" az="); Serial.print(az, 2);
  Serial.print(" | pitch="); Serial.print(pitch, 1);
  Serial.print(" roll="); Serial.println(roll, 1);
  delay(200);
}

11Kendini Test Et

Doğru seçeneği bulduğunuzda kısa bir açıklama görüntülenir.

1) Arduino UNO'da I²C hatları hangi pinlerdir?

✓ UNO'da I²C donanımı A4 (SDA) ve A5 (SCL) pinlerine bağlıdır; D0/D1 seri port (UART), D11/D13 SPI hatlarıdır.

2) I²C LCD programı yüklendi, arka ışık yanıyor ama yazı görünmüyor. İlk ne yapılmalı?

✓ En sık iki neden yanlış kontrast ayarı ve modülün 0x27 yerine 0x3F adresli olmasıdır.

3) lcd.setCursor(5, 1); imleci nereye götürür?

✓ Sıra (sütun, satır)'dır ve sayım 0'dan başlar: sütun 5 = 6. sütun, satır 1 = ikinci (alt) satır.

4) MPU6050 ±2 g aralığında, düz bir masada dururken Z ekseninin ham değeri yaklaşık kaçtır?

✓ Duyarlılık 16384 LSB/g'dir ve masada Z ekseni +1 g ölçer: ≈ 16384 (ham/16384 = 1 g).

5) Yalnızca ivmeölçer verisiyle hangi açı hesaplanamaz?

✓ Yaw, yerçekimi vektörüne dik düzlemde dönmedir; bu dönüşte yerçekiminin eksenlere dağılımı değişmez. Jiroskop veya manyetometre gerekir.

12Ödev ve Özet

Ödev

  1. LCD'nin üst satırında "Sure:" yazısı, alt satırında millis() ile hesaplanan geçen süreyi dd:ss (dakika:saniye) biçiminde gösteren bir kronometre yapın.
  2. createChar() ile ş, ı, ğ, ç harflerini tanımlayıp LCD'ye "Işık" ve "Sıcaklık" kelimelerini doğru yazın.
  3. MPU6050 ile bir dijital su terazisi yapın: roll açısını LCD'nin üst satırında bir "kabarcık" karakterinin konumuyla (0–15. sütun), alt satırda sayısal olarak gösterin.
  4. 11. haftadaki HC-SR04 mesafe ölçeri LCD'ye taşıyın; alt satırda mesafeyle orantılı bir çubuk grafik (█ karakterleri: lcd.write(255)) çizin.
2. ödev için ipucu (tıklayın)
ozel_karakter_ipucu.ino
// İpucu: createChar ile Türkçe karakter tanımlama (5x8 nokta, her satır 5 bit)
byte sHarfi[8] = { B00000, B01111, B10000, B01110, B00001, B11110, B00100, B01000 }; // ş
byte iHarfi[8] = { B00000, B00000, B01100, B00100, B00100, B00100, B01110, B00000 }; // ı

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.createChar(0, sHarfi);   // CGRAM 0. konuma ş
  lcd.createChar(1, iHarfi);   // CGRAM 1. konuma ı
  lcd.setCursor(0, 0);         // createChar'dan sonra mutlaka setCursor/home çağırın
  lcd.print("I");              // büyük I (noktasız) ASCII'de vardır
  lcd.write(byte(0));          // ş
  lcd.write(byte(1));          // ı
  lcd.print("k");              // ekranda: "Işık"
}

Özet

  • 16×2 LCD, HD44780 denetleyicisiyle çalışır; satır başına 40 karakterlik DDRAM'in 16'sı görünür.
  • Paralel bağlantı 6 pin (LiquidCrystal, begin(16,2)), I²C modülü yalnızca SDA/SCL (A4/A5) kullanır (LiquidCrystal_I2C, Kütüphane Yöneticisi'nden kurulur).
  • Adres genellikle 0x27 veya 0x3F'dir; emin değilseniz I²C tarayıcı çalıştırın. Kontrast trimpotunu unutmayın.
  • setCursor(sütun, satır) 0'dan sayar; clear() yerine boşlukla üzerine yazmak titremeyi önler.
  • MPU6050: 3 eksen ivme + 3 eksen jiroskop, I²C 0x68; ±2 g'de 16384 LSB/g.
  • roll = atan2(ay, az), pitch = atan2(−ax, √(ay²+az²)); yaw ivmeden bulunamaz.
