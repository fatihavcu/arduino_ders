2Dijital Giriş ve digitalRead()

Bir pin pinMode(pin, INPUT) ile giriş yapıldığında, Arduino o pindeki gerilime bakarak bir mantık değeri üretir. digitalRead(pin) bu değeri HIGH (1) veya LOW (0) olarak döndürür.

FonksiyonAçıklama
pinMode(pin, INPUT)Pini yüksek empedanslı giriş yapar (varsayılan mod).
pinMode(pin, INPUT_PULLUP)Pini giriş yapar ve içerideki ≈ 20–50 kΩ'luk pull-up direncini 5 V'a bağlar.
digitalRead(pin)Pindeki gerilimi okur; HIGH veya LOW döndürür (int değişkende saklanabilir).

ATmega328P'nin 5 V'taki eşikleri (veri sayfası): VIL ≤ 0,3·VCC = 1,5 V → kesin LOW; VIH ≥ 0,6·VCC = 3,0 V → kesin HIGH. Aradaki bölgede okunan değer belirsizdir.

3Buton (Push Button) Tanıtımı

Breadboard'a uygun 4 bacaklı mikro buton (tact switch), basıldığı sürece iletken olan, bırakılınca açılan (normalde açık, NO) bir anahtardır. Dört bacak ikişer ikişer içeriden zaten birbirine bağlıdır; butona basıldığında bu iki çift birbirine bağlanır.

Şekil 1. Mikro butonun iç bağlantıları: mavi ve yeşil kesikli çizgiler her zaman bağlı olan bacak çiftleridir

Doğru bağlantı kuralı

  • Bacak 1–2 ve 3–4 hep bağlıdır; bunları anahtar uçları olarak kullanmak işe yaramaz (buton hep "basılı" görünür).
  • Anahtar olarak çapraz bacakları (ör. 1 ve 4) kullanmak her zaman güvenlidir.
  • Breadboard'da buton genellikle orta kanalın üzerine oturtulur; böylece bağlı çiftler kanalın iki yanındaki farklı sütunlara düşer.
  • Bacak düzeni üreticiye göre değişebilir: emin değilseniz multimetrenin süreklilik modu ile hangi bacakların hep bağlı olduğunu kontrol edin (2. hafta).
Butonlar, anahtarlar, reed röleler, limit anahtarları ve PIR sensörünün çıkışı gibi "açık/kapalı" bilgi veren her eleman, bu hafta öğrendiğimiz dijital giriş mantığıyla okunur.

4Havada Kalan (Floating) Giriş Problemi

Butonun bir ucu 5 V'a, diğer ucu doğrudan pin 2'ye bağlansa ne olur? Butona basıldığında pin 5 V'a bağlanır ve HIGH okunur. Ancak buton bırakıldığında pin hiçbir yere bağlı değildir: giriş empedansı çok yüksek olduğu için çevredeki elektrik alanlarından, parmağınızdan, hatta yakındaki kablolardan gürültü toplar. digitalRead() rastgele 0 ve 1 değerleri döndürür. Buna havada kalan (floating) giriş denir.

🔬 Simülasyon: Dirençsiz buton girişi ne okur?

Kullanılmayan veya bir yere bağlı olmayan giriş pinini okumak anlamsız sonuçlar verir. Her dijital girişin, anahtar açıkken de kesin bir gerilime (0 V veya 5 V) bağlı olması gerekir. Bunu bir pull-down veya pull-up direnciyle sağlarız.

5Pull-down, Pull-up ve INPUT_PULLUP

Pin, büyük değerli bir direnç (genellikle 10 kΩ) üzerinden GND'ye veya 5 V'a bağlanarak "varsayılan" bir değere çekilir. Buton basıldığında bu varsayılan değer ezilir.

Bırakıldı → LOW, basıldı → HIGH (şemaya tıklayın)
Bırakıldı → HIGH, basıldı → LOW (ters mantık)
Pull-down (harici 10 kΩ)INPUT_PULLUP (dahili direnç)
Bağlantı5V — buton — pin; pin — 10 kΩ — GNDpin — buton — GND (harici direnç yok)
BırakılmışkenLOW (0)HIGH (1)
BasılıykenHIGH (1)LOW (0)
Basılıyken akımI = 5 V / 10 kΩ = 0,5 mA≈ 5 V / 35 kΩ ≈ 0,1–0,25 mA
KodpinMode(2, INPUT);pinMode(2, INPUT_PULLUP);
Direnç neden 10 kΩ? Çok küçük seçilirse (ör. 100 Ω) basıldığında 50 mA akım boşa harcanır; çok büyük seçilirse (ör. 10 MΩ) pin yine gürültüye duyarlı hâle gelir. 4,7–100 kΩ aralığı pratikte sorunsuz çalışır. Butonu dirençsiz şekilde 5V ile GND arasına bağlamayın: basıldığı anda kısa devre olur.

6Devre Kurulumu: Buton ve LED

Buton pin 2'ye 10 kΩ pull-down direnciyle, LED ise 220 Ω dirençle pin 8'e bağlanır. Aşağıdaki şemada butona tıklayıp basılı tutun: akım yolları ve digitalRead(2) değeri, buton_led.ino programına göre canlı olarak değişir.

7Program 1 ve 2: Buton ile LED Kontrolü

buton_led.ino
// Program 1: Buton basılıyken LED yanar (harici 10 kΩ pull-down)
const int BUTON = 2;     // Buton pin 2'de
const int LED = 8;       // LED pin 8'de
int butonDurumu = 0;     // Okunan değer burada saklanır

void setup() {
  pinMode(BUTON, INPUT);       // Pin 2 giriş
  pinMode(LED, OUTPUT);        // Pin 8 çıkış
  Serial.begin(9600);
}

void loop() {
  butonDurumu = digitalRead(BUTON);   // HIGH (1) veya LOW (0)

  if (butonDurumu == HIGH) {          // Basılı mı?
    digitalWrite(LED, HIGH);          // Evet: LED'i yak
  } else {
    digitalWrite(LED, LOW);           // Hayır: LED'i söndür
  }

  Serial.print("Buton: ");
  Serial.println(butonDurumu);        // Seri Monitör'e 1 veya 0 yaz
  delay(100);                         // Saniyede 10 okuma
}
buton_pullup.ino
// Program 2: Dahili pull-up ile buton (harici direnç YOK)
// Bağlantı: pin 2 — buton — GND
const int BUTON = 2;
const int LED = 8;

void setup() {
  pinMode(BUTON, INPUT_PULLUP);  // Dahili pull-up açık
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int okunan = digitalRead(BUTON);  // Bırakılmış: HIGH, basılı: LOW

  if (okunan == LOW) {              // Ters mantık!
    digitalWrite(LED, HIGH);
    Serial.println("BASILDI");
  } else {
    digitalWrite(LED, LOW);
    Serial.println("birakildi");
  }
  delay(100);
}

8Buton Sıçraması (Bounce) ve Debounce

Butonun içindeki metal kontaklar birbirine çarptığında hemen oturmaz; birkaç milisaniye boyunca titreşerek açılıp kapanır. İnsan bunu fark etmez, ancak saniyede on binlerce kez loop() çalıştıran Arduino tek bir basışı birden fazla basış olarak görebilir. Bu olaya sıçrama (bounce), giderilmesine debounce denir.

Şekil 3. İdeal ve gerçek buton sinyali: basma ve bırakma anlarında kısa süreli sıçramalar

Yöntem 1: Bekle ve tekrar oku

Değişim fark edilince ≈ 50 ms bekleyip pin yeniden okunur. Basit, ama bekleme sırasında program durur.

Yöntem 2: millis() ile zaman filtresi

Ham sinyalin son değiştiği an kaydedilir; sinyal 50 ms boyunca değişmeden kalırsa yeni durum kabul edilir. Program hiç durmaz (Arduino'nun resmi Debounce örneğindeki yöntem).

Donanımsal debounce da mümkündür: butona paralel ≈ 100 nF kondansatör, kontak titreşimlerini yumuşatır. Bu derste yazılımsal yöntemleri kullanacağız.

9Aç-Kapa (Toggle): Durum Değişkeni ve Kenar Algılama

Bir kez basınca LED yansın, bir kez daha basınca sönsün istiyorsak "buton basılı mı?" sorusu yetmez; çünkü buton basılı tutulduğu sürece LED sürekli açılıp kapanır. Bunun yerine butonun yeni basıldığı anı (LOW → HIGH geçişi, yükselen kenar) yakalamalı ve LED'in durumunu bir durum değişkeninde saklamalıyız.

toggle_basit.ino
// Program 3: Toggle — basit debounce (bekle ve tekrar oku)
const int BUTON = 2, LED = 8;      // Devre: pull-down'lı buton pin 2, LED pin 8
bool ledDurumu = false;            // LED şu an açık mı?
int oncekiOkuma = LOW;             // Bir önceki loop'taki buton değeri

void setup() {
  pinMode(BUTON, INPUT);
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int okuma = digitalRead(BUTON);

  if (okuma == HIGH && oncekiOkuma == LOW) {   // Yükselen kenar: yeni basıldı
    delay(50);                                  // Sıçramaların bitmesini bekle
    okuma = digitalRead(BUTON);                 // Tekrar oku
    if (okuma == HIGH) {                        // Hâlâ basılıysa gerçek basıştır
      ledDurumu = !ledDurumu;                   // Durumu tersine çevir
      digitalWrite(LED, ledDurumu);
      Serial.print("LED: ");
      Serial.println(ledDurumu ? "ACIK" : "KAPALI");
    }
  }
  oncekiOkuma = okuma;                          // Sonraki tur için sakla
}
toggle_millis.ino
// Program 4: Toggle + basma sayacı — millis() ile debounce (program hiç beklemez)
const int BUTON = 2, LED = 8;
const unsigned long DEBOUNCE_SURE = 50;   // ms

int butonDurumu = LOW;          // Onaylanmış (kararlı) buton durumu
int sonOkuma = LOW;             // Bir önceki ham okuma
unsigned long sonDegisim = 0;   // Ham okumanın son değiştiği an
bool ledDurumu = false;
int basmaSayisi = 0;

void setup() {
  pinMode(BUTON, INPUT);
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int okuma = digitalRead(BUTON);

  if (okuma != sonOkuma) {                     // Ham sinyal değişti (sıçrama olabilir)
    sonDegisim = millis();                     // Zamanlayıcıyı yeniden başlat
  }

  if (millis() - sonDegisim > DEBOUNCE_SURE) { // 50 ms boyunca sabit kaldıysa
    if (okuma != butonDurumu) {                // ve kararlı durumdan farklıysa
      butonDurumu = okuma;                     // yeni durumu kabul et
      if (butonDurumu == HIGH) {               // yalnızca BASMA anında
        ledDurumu = !ledDurumu;
        basmaSayisi++;
        digitalWrite(LED, ledDurumu);
        Serial.print("Basma: ");
        Serial.print(basmaSayisi);
        Serial.print("  LED: ");
        Serial.println(ledDurumu ? "ACIK" : "KAPALI");
      }
    }
  }
  sonOkuma = okuma;
}

🔬 Simülasyon: toggle_millis.ino — sıçramalı buton ve debounce (zaman 1 ms çözünürlükle simüle edilir)

11Kendini Test Et

1) pinMode(2, INPUT_PULLUP) ile ayarlanmış ve pin 2 — buton — GND şeklinde bağlanmış bir butona basılmıyorken digitalRead(2) ne döndürür?

✓ Dahili pull-up direnci pini 5 V'a çeker; buton açıkken pin HIGH okunur. Basılınca GND'ye bağlanır ve LOW okunur.

2) Pull-down direnci olmadan, yalnızca 5V — buton — pin 2 bağlantısında buton bırakıldığında neden rastgele değerler okunur?

✓ Yüksek empedanslı giriş bir yere bağlı değilse elektriksel gürültüyle rastgele HIGH/LOW arasında gezinir.

3) 5 V ve 10 kΩ pull-down direnciyle kurulan devrede butona basıldığında dirençten geçen akım kaçtır?

✓ I = V / R = 5 / 10 000 = 0,0005 A = 0,5 mA. Bu yüzden pull-down direnci enerji israfına yol açmaz.

4) Butonda sıçrama (bounce) tipik olarak ne kadar sürer ve debounce süresi genellikle kaç seçilir?

✓ Kontak titreşimi birkaç milisaniye sürer; 20–50 ms'lik filtre insan için fark edilmez, sıçramaları ise güvenle örter.

5) Toggle (aç-kapa) programında buton basılı tutulduğunda LED'in sürekli yanıp sönmemesi için ne yapılır?

✓ Seviye (basılı mı?) yerine kenar (yeni mi basıldı?) kontrol edilir; bunun için önceki okuma bir değişkende tutulur.

12Ödev ve Özet

Ödev

  1. İki buton kullanın: pin 2'deki buton LED'i yaksın, pin 3'teki buton söndürsün. Butonlardan birini harici pull-down, diğerini INPUT_PULLUP ile bağlayın.
  2. toggle_millis.ino programını, her 5. basışta LED'in 3 kez hızlıca yanıp sönmesini sağlayacak şekilde geliştirin (basmaSayisi % 5 == 0).
  3. 3. haftanın trafik lambasına bir yaya butonu ekleyin: butona basıldığında, yeşil ışık en geç 2 saniye içinde sarıya dönsün. (İpucu: delay() butonu kaçırır, millis() kullanın.)
  4. Program 3'ü INPUT_PULLUP kullanacak şekilde yeniden yazın (kenar ve karşılaştırmalar nasıl değişir?).
1. ödev için ipucu (tıklayın)
iki_buton_ipucu.ino
const int YAK_BUTON = 2;      // 5V — buton — pin 2, pin 2 — 10 kΩ — GND
const int SONDUR_BUTON = 3;   // pin 3 — buton — GND (dahili pull-up)
const int LED = 8;

void setup() {
  pinMode(YAK_BUTON, INPUT);
  pinMode(SONDUR_BUTON, INPUT_PULLUP);
  pinMode(LED, OUTPUT);
}

void loop() {
  if (digitalRead(YAK_BUTON) == HIGH) {          // pull-down: basılı = HIGH
    digitalWrite(LED, HIGH);
  } else if (digitalRead(SONDUR_BUTON) == LOW) { // pull-up: basılı = LOW
    digitalWrite(LED, LOW);
  }
  // Hiçbiri basılı değilse LED önceki durumunu korur
}

Özet

  • digitalRead(pin) girişteki gerilimi HIGH/LOW olarak okur; 5 V sistemde ≥ 3 V HIGH, ≤ 1,5 V LOW'dur.
  • Bağlı olmayan giriş havada kalır ve rastgele okunur; pull-down veya pull-up direnci şarttır.
  • Pull-down: bırakılınca LOW, basılınca HIGH. INPUT_PULLUP: harici direnç yok, bırakılınca HIGH, basılınca LOW.
  • Mekanik butonlar birkaç ms sıçrar; bekle-tekrar-oku veya millis() tabanlı debounce kullanılır.
  • Toggle için durum değişkeni ve kenar algılama (önceki okuma ile karşılaştırma) gerekir.
  • Serial.println(digitalRead(pin)) ile ham değeri izlemek, hata ayıklamanın ilk adımıdır.
