1Haftanın Hedefleri

  • Servo motorun iç yapısını ve kapalı çevrim (geri beslemeli) konum kontrolünü açıklayabilmek
  • 50 Hz, 1–2 ms darbe genişlikli servo sinyalini yorumlayabilmek ve açı–darbe ilişkisini hesaplayabilmek
  • Servo.h kütüphanesinin attach(), write(), writeMicroseconds() fonksiyonlarını kullanabilmek
  • Potansiyometre ile servo konumunu kontrol eden ve süpürme (sweep) yapan programlar yazabilmek
  • Su seviye sensörünün çalışma ilkesini bilmek, analog okumayı kalibre edip LED'lerle göstermek
  • Seviyeye göre servo ile kapak açıp kapatan, histerezisli bir otomatik kontrol sistemi tasarlayabilmek

2Servo Motor Nedir?

Servo motor, milini istenen açıya götürüp orada tutabilen bir motordur. Sürekli dönen DC motordan farkı, içinde bir konum algılayıcısı (potansiyometre) ve bir kontrol devresi bulunmasıdır. Robot kolları, RC modeller, kamera yönlendirme (pan-tilt), otomatik kapı ve vana mekanizmalarında kullanılır.

Şekil 1. Servo motorun iç yapısı: kontrol devresi, istenen konum (PWM) ile potansiyometreden okunan gerçek konumu karşılaştırır ve fark sıfır olana kadar motoru döndürür.

3PWM Sinyali ile Konum Kontrolü

Servo, sinyal pinine yaklaşık her 20 ms'de bir (50 Hz) gelen darbenin genişliğine bakar. Darbe genişliği kolun açısını belirler; darbe sürekli tekrarlandığı sürece servo konumunu korur.

Şekil 2. Standart servo kontrol sinyali: her 20 ms'de bir gelen darbenin genişliği kolun açısını belirler (ölçeksiz).
darbe genişliği ≈ 1 ms + (açı / 180°) · 1 ms   (1 ms → 0°, 1,5 ms → 90°, 2 ms → 180°)

Görev oranı (duty cycle) çok küçüktür: 1,5 ms / 20 ms = %7,5. Bu yüzden servo sinyali, LED parlaklığında kullandığımız analogWrite() (≈ 490/980 Hz) ile üretilemez; zamanlamayı Servo.h kütüphanesi Timer1 donanım zamanlayıcısıyla yapar.

Pratikte SG90 gibi servoların tam 0°–180° dönebilmesi için ≈ 0,5–2,4 ms aralığı gerekir. Bu nedenle Servo.h varsayılan olarak 544 µs (0°) – 2400 µs (180°) kullanır. Servo uç noktalarda zorlanıp vızıldıyorsa sınırları attach(pin, 1000, 2000) gibi daraltın.

4Servo.h Kütüphanesi

Servo.h, Arduino IDE ile birlikte gelen standart bir kütüphanedir; Kütüphane Yöneticisi'nden ayrıca kurmanız gerekmez. Programın başına #include <Servo.h> yazılır ve her servo için bir Servo nesnesi tanımlanır.

UNO'da Servo.h Timer1'i kullandığı için, kütüphane kullanılırken D9 ve D10 pinlerinde analogWrite() çalışmaz (servo pini olarak kullanılabilirler).
Tek bir SG90 USB'den beslenen UNO'nun 5V pininden çalıştırılabilir. Ancak birden fazla servo ya da yük altında çalışan servolar için harici 5 V güç kaynağı kullanın ve kaynağın GND'sini Arduino GND'si ile birleştirin. Besleme hattına 100–470 µF kondansatör eklemek, servonun kalkış akımının Arduino'yu resetlemesini önler.

5Devre Şeması: Servo ve Potansiyometre

Şekil 4. Servo ve potansiyometre bağlantısı: servo sinyali D9, potansiyometre orta ucu A0. Siyah noktalar bağlantı noktalarıdır; nokta olmayan kesişimler birbirine bağlı değildir. Servo kolu animasyonla süpürme hareketi yapar.

Potansiyometrenin iki dış ucu 5V ve GND'ye, orta ucu (sürgü) A0'a bağlanır; orta uçtaki gerilim 0–5 V arasında değişir ve analogRead() ile 0–1023 olarak okunur (7. hafta).

6Uygulama 1–2: Sweep ve Potansiyometre ile Servo

sweep.ino
// Hafta 12 – Uygulama 1: Sweep (servo kolunu 0°–180° arasında süpürme)
#include <Servo.h>   // Arduino IDE ile birlikte gelir, ayrıca kurulum gerekmez

Servo servom;        // bir servo nesnesi oluştur
int pos = 0;         // servo açısı (derece)

void setup() {
  servom.attach(9);  // servonun sinyal kablosu D9'a bağlı
}

void loop() {
  for (pos = 0; pos <= 180; pos += 1) {   // 0° -> 180°
    servom.write(pos);                    // kolu 'pos' açısına götür
    delay(15);                            // servonun yetişmesi için bekle
  }
  for (pos = 180; pos >= 0; pos -= 1) {   // 180° -> 0°
    servom.write(pos);
    delay(15);
  }
}
pot_servo.ino
// Hafta 12 – Uygulama 2: Potansiyometre ile servo kontrolü
#include <Servo.h>

Servo servom;
const int potPin = A0;     // potansiyometre orta ucu
int oncekiAci = -1;        // son yazdırılan açı

void setup() {
  Serial.begin(9600);
  servom.attach(9);
}

void loop() {
  int deger = analogRead(potPin);          // 0 – 1023
  int aci = map(deger, 0, 1023, 0, 180);   // 0° – 180°
  servom.write(aci);

  if (aci != oncekiAci) {                  // yalnızca açı değişince yaz
    Serial.print("Pot: ");
    Serial.print(deger);
    Serial.print("  Açı: ");
    Serial.println(aci);
    oncekiAci = aci;
  }
  delay(15);
}

7Su Seviye Sensörü

Yaygın olarak kullanılan kırmızı renkli su seviye sensörü modülünde, birbirine paralel açık bakır izler bulunur. İzlerin bir kısmı beslemeye, diğerleri bir NPN transistörün (genellikle S8050) beyzine bağlıdır. Su iletken olduğundan, sensör suya daldıkça izler arasındaki direnç azalır, transistör daha fazla iletime geçer ve S çıkışındaki gerilim yükselir. Bu gerilim analogRead() ile okunur.

Okunan değerler doğrusal değildir ve suyun iletkenliğine (musluk suyu, saf su, tuzlu su), sıcaklığa ve sensörün yaşına göre değişir. Tablo yalnızca fikir vermek içindir; kendi düzeneğinizde kalibrasyon yapın. Bu sensör hassas ölçüm için değil, seviye var/yok ve kaba seviye tespiti içindir.
Sürekli gerilim altındaki izler suda elektroliz nedeniyle zamanla aşınır (korozyon). Ömrü uzatmak için sensörü yalnızca okuma anında beslemek iyi bir uygulamadır:
sensor_guc.ino (parça)
// Korozyonu azaltmak için sensörü yalnızca okuma anında besleme
// (sensörün + ucu 5V yerine D7'ye bağlanır; modül < 20 mA çeker)
const int sensorGuc = 7;

int seviyeOku() {
  digitalWrite(sensorGuc, HIGH);   // sensörü aç
  delay(10);                       // çıkışın oturması için kısa bekleme
  int v = analogRead(A1);
  digitalWrite(sensorGuc, LOW);    // sensörü kapat
  return v;
}
// setup() içinde: pinMode(sensorGuc, OUTPUT); digitalWrite(sensorGuc, LOW);

8Devre Şeması: Seviye Kontrol Sistemi

Şekil 7. Seviye kontrol sistemi: su seviye sensörü S → A1 (+ → 5V, − → GND), LED'ler D2–D4 (220 Ω), kapak servosu D9. Siyah noktalar bağlantı noktalarıdır.

Bu devrede sensör doğrudan 5V hattından beslenmiştir. Yukarıdaki korozyon önleyici yöntemi kullanacaksanız sensörün + ucunu D7'ye taşıyın.

9Uygulama 3–4: Seviye Okuma ve LED Göstergesi

Kalibrasyon adımları:

  1. Uygulama 3'ü yükleyin; sensör kuruyken Seri Monitörde okunan değeri KURU sabitine yazın.
  2. Sensörün izli bölgesini bir bardak suya tamamen daldırın; okunan değeri DOLU sabitine yazın.
  3. Birkaç ara seviyede değerleri not edip LED eşiklerini (ESIK_DUSUK, ESIK_ORTA, ESIK_YUKSEK) belirleyin.
seviye_okuma.ino
// Hafta 12 – Uygulama 3: Su seviye sensörünü okuma ve kalibrasyon
const int sensorPin = A1;
const int KURU = 0;      // sensör kuruyken okunan değer (kendi ölçümünüzü yazın)
const int DOLU = 550;    // izli bölge tamamen sudayken okunan değer

void setup() {
  Serial.begin(9600);
}

void loop() {
  int ham = analogRead(sensorPin);               // 0 – 1023
  int sinirli = constrain(ham, KURU, DOLU);      // aralık dışını kırp
  int yuzde = map(sinirli, KURU, DOLU, 0, 100);  // yaklaşık doluluk %
  float volt = ham * 5.0 / 1023.0;               // S pinindeki gerilim

  Serial.print("Ham: ");
  Serial.print(ham);
  Serial.print("  Gerilim: ");
  Serial.print(volt, 2);
  Serial.print(" V  Seviye: %");
  Serial.println(yuzde);
  delay(500);
}
seviye_led.ino
// Hafta 12 – Uygulama 4: Seviyeyi LED çubuğuyla gösterme
const int sensorPin = A1;
const int ledDusuk = 2;    // yeşil
const int ledOrta  = 3;    // sarı
const int ledYuksek = 4;   // kırmızı

const int ESIK_DUSUK  = 150;   // eşikler kalibrasyona göre ayarlanır
const int ESIK_ORTA   = 300;
const int ESIK_YUKSEK = 450;

void setup() {
  Serial.begin(9600);
  pinMode(ledDusuk, OUTPUT);
  pinMode(ledOrta, OUTPUT);
  pinMode(ledYuksek, OUTPUT);
}

void loop() {
  int s = analogRead(sensorPin);
  digitalWrite(ledDusuk,  s >= ESIK_DUSUK  ? HIGH : LOW);
  digitalWrite(ledOrta,   s >= ESIK_ORTA   ? HIGH : LOW);
  digitalWrite(ledYuksek, s >= ESIK_YUKSEK ? HIGH : LOW);
  Serial.println(s);
  delay(200);
}

map() doğrusal bir dönüşüm yaptığından, doğrusal olmayan sensörde elde edilen yüzde yalnızca yaklaşıktır. Daha doğru sonuç için birkaç ölçüm noktası arasında parça parça doğrusal (tablo ile) dönüşüm yapılabilir.

10Uygulama 5: Servo Kapaklı Otomatik Seviye Kontrolü

Tank dolduğunda servo bir tahliye kapağını açar, seviye yeterince düşünce kapatır. Tek bir eşik kullanılsaydı, seviye eşik civarında dalgalandığında kapak saniyede birkaç kez açılıp kapanırdı (titreşim, chattering). Bunu önlemek için iki farklı eşik kullanılır: buna histerezis denir (termostatlar da aynı yöntemle çalışır).

s ≥ 450 → kapak AÇ (90°)   |   s < 300 → kapak KAPAT (0°)   |   300 ≤ s < 450 → durumu koru
seviye_kapak.ino
// Hafta 12 – Uygulama 5: Seviyeye göre servo ile tahliye kapağı (histerezisli)
#include <Servo.h>

Servo kapak;
const int sensorPin = A1;
const int servoPin = 9;
const int ledDusuk = 2, ledOrta = 3, ledYuksek = 4;

const int ACMA_ESIGI  = 450;   // bu değere ulaşınca kapağı aç
const int KAPAMA_ESIGI = 300;  // bunun altına inince kapağı kapat
const int KAPALI_ACI = 0;
const int ACIK_ACI   = 90;

bool kapakAcik = false;

void setup() {
  Serial.begin(9600);
  pinMode(ledDusuk, OUTPUT);
  pinMode(ledOrta, OUTPUT);
  pinMode(ledYuksek, OUTPUT);
  kapak.attach(servoPin);
  kapak.write(KAPALI_ACI);       // başlangıçta kapak kapalı
}

void loop() {
  int s = analogRead(sensorPin);

  digitalWrite(ledDusuk,  s >= 150 ? HIGH : LOW);
  digitalWrite(ledOrta,   s >= 300 ? HIGH : LOW);
  digitalWrite(ledYuksek, s >= 450 ? HIGH : LOW);

  // Histerezis: iki farklı eşik, kapağın eşik civarında titreşmesini önler
  if (!kapakAcik && s >= ACMA_ESIGI) {
    kapak.write(ACIK_ACI);
    kapakAcik = true;
  } else if (kapakAcik && s < KAPAMA_ESIGI) {
    kapak.write(KAPALI_ACI);
    kapakAcik = false;
  }

  Serial.print("Seviye: ");
  Serial.print(s);
  Serial.print("  Kapak: ");
  Serial.println(kapakAcik ? "AÇIK" : "KAPALI");
  delay(200);
}

Model: sensör değeri s ≈ 620·(1 − e−h/18) (h: izli bölgedeki su yüksekliği, mm; izli bölge 40 mm). Simülasyon zamanı gerçek zamanın 2 katı hızındadır. Debiyi 2 mm/s civarında tutup kapağın 450'de açılıp 300'ün altında kapandığını gözleyin.

11Kendini Test Et

Doğru seçeneği bulduğunuzda kısa bir açıklama görüntülenir.

1) Standart bir servo sinyalinin periyodu ve frekansı nedir?

✓ Servo her 20 ms'de (50 Hz) bir gelen darbenin genişliğine göre konum alır.

2) 1,5 ms genişlikli darbe standart bir servoda hangi açıya karşılık gelir?

✓ 1 ms → 0°, 2 ms → 180° ise ortadaki 1,5 ms → 90° (orta konum).

3) servom.write(45); komutu ne yapar?

✓ Standart (180°) servolarda write() mutlak açı verir; servo bu konuma gidip orada kalır.

4) UNO'da Servo.h kullanılırken hangi pinlerde analogWrite() çalışmaz?

✓ Servo.h, UNO'da Timer1'i kullanır; Timer1 D9 ve D10'un PWM'ini üretir.

5) Uygulama 5'te neden iki farklı eşik (450 ve 300) kullanıldı?

✓ Histerezis: açma ve kapama eşikleri arasındaki boşluk, gürültü ve dalgalanmalarda kararsız davranışı (chattering) önler.

12Ödev ve Özet

Ödev

  1. İki servo ve iki potansiyometre ile bir pan-tilt (yatay/dikey) kamera tutucu düzeneği programlayın (servolar D9 ve D10'a).
  2. Sweep programını, süpürme hızı A0'daki potansiyometreyle ayarlanacak şekilde değiştirin.
  3. Seviye %90'ı geçtiğinde buzzer ile alarm veren ve Seri Monitöre "TAŞMA UYARISI" yazan bir sistem ekleyin.
  4. Kapağı yalnızca açık/kapalı değil, seviyeyle orantılı açan bir program yazın (300 → 0°, 550 → 90°). Histerezisli ve orantılı kontrolü karşılaştırın.
2. ödev için ipucu (tıklayın)
sweep_hiz_ipucu.ino
// İpucu: süpürme hızını potansiyometre ile ayarlamak
#include <Servo.h>
Servo servom;

void setup() { servom.attach(9); }

void loop() {
  for (int pos = 0; pos <= 180; pos++) {
    servom.write(pos);
    int bekle = map(analogRead(A0), 0, 1023, 2, 40);  // adım başına 2–40 ms
    delay(bekle);
  }
  for (int pos = 180; pos >= 0; pos--) {
    servom.write(pos);
    delay(map(analogRead(A0), 0, 1023, 2, 40));
  }
}

Özet

  • Servo = DC motor + dişli + potansiyometre + kontrol devresi; kapalı çevrimle açıyı korur.
  • Sinyal 50 Hz (20 ms); darbe ≈ 1 ms → 0°, 1,5 ms → 90°, 2 ms → 180° (Servo.h varsayılanı 544–2400 µs).
  • #include <Servo.h> → attach(pin) → write(açı); UNO'da D9/D10 PWM'i devre dışı kalır.
  • Su seviye sensörü iletkenliğe dayalı analog çıkış verir; doğrusal değildir, kalibrasyon gerekir, korozyona dikkat.
  • Açma/kapama kararlarında histerezis (iki eşik) kullanmak kararlı bir kontrol sağlar.
