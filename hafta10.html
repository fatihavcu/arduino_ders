2Sıcaklık Sensörü Türleri

3LM35 Sensörünü Tanıyalım

Şekil 2. LM35 (TO-92 kılıf) bacak yapısı: düz yüz size bakarken soldan sağa +Vs, Vout, GND

LM35, Texas Instruments tarafından üretilen, çıkış gerilimi santigrat derece ile doğru orantılı olan hassas bir entegre sıcaklık sensörüdür. İçindeki yarı iletken devre, sıcaklıkla değişen transistör eklem gerilimini yükselterek doğrusal bir çıkış verir.

  • Çıkış eğimi: 10 mV/°C (0 °C'de 0 V, 25 °C'de 250 mV, 100 °C'de 1 V)
  • Besleme: 4–30 V (Arduino'nun 5 V pini uygundur)
  • Doğruluk: 25 °C'de ±0,5 °C (LM35A için ±0,25 °C)
  • Akım tüketimi ≈ 60 µA → kendi kendini ısıtma ihmal edilebilir (≈ 0,1 °C)
  • Kalibrasyon gerektirmez
Vout = 10 mV/°C × T   ⟹   T(°C) = Vout(mV) / 10
LM35'i ters takarsanız (+Vs ile GND yer değiştirirse) birkaç saniye içinde elle tutulamayacak kadar ısınır ve bozulur. Bağlantıyı enerji vermeden önce mutlaka kontrol edin. Düz yüz size bakarken sol = +5 V, sağ = GND.
Temel bağlantıda (yalnızca 3 bacak) LM35 negatif gerilim üretemez; bu nedenle 0 °C'nin altındaki sıcaklıklar okunamaz. Negatif sıcaklık ölçümü için çıkışa GND'ye değil negatif beslemeye bağlı bir direnç eklenir veya TMP36 kullanılır.

4Gerilimden Sıcaklığa: ADC Hesabı

Arduino UNO'nun ADC'si 0–5 V aralığını 1024 basamağa (10 bit) böler. Bir basamak 5000 mV / 1024 ≈ 4,88 mV'dir. Okunan sayıdan önce gerilime, sonra sıcaklığa geçilir:

V(mV) = analogRead · 5000 / 1024   ⟹   T(°C) = analogRead · 5000 / 1024 / 10

Çözümlü örnek 1: analogRead = 51 → V = 51 · 5000 / 1024 = 249,0 mV → T = 24,9 °C

Çözümlü örnek 2: Ortam 37 °C ise LM35 çıkışı 370 mV olur; ADC = ⌊370 · 1024 / 5000⌋ = 75. Arduino bunu 75 · 5000/1024/10 = 36,6 °C olarak hesaplar (basamaklama hatası).

Çözünürlük: Bir ADC basamağı 4,88 mV = ≈ 0,49 °C'ye karşılık gelir. Yani 5 V referansta sıcaklık yaklaşık yarım derecelik adımlarla değişir.

SıcaklıkVoutADC (5 V ref.)ADC (1,1 V ref.)
0 °C0 mV00
20 °C200 mV40186
25 °C250 mV51232
50 °C500 mV102465
100 °C1000 mV204930
LM35 en fazla 1,5 V üretir; 5 V referansta ADC'nin yalnızca ≈ %30'u kullanılır. analogReference(INTERNAL); komutu ile UNO'nun dahili 1,1 V referansı seçilirse basamak 1100/1024 ≈ 1,07 mV = ≈ 0,11 °C olur (ölçüm üst sınırı 110 °C). Bu durumda formül T = okunan · 1100.0 / 1024.0 / 10.0 olur. Referans değiştikten sonraki ilk birkaç okuma atılmalıdır.

6Uygulama 1: Seri Monitörde Sıcaklık

İlk programımız LM35'i saniyede bir okur ve ADC değerini, gerilimi ve sıcaklığı Seri Monitöre yazar. Çıktısını Simülasyon 1'deki Seri Monitörde görebilirsiniz.

LM35_Seri.ino
// LM35 ile sıcaklık ölçümü ve Seri Monitöre yazdırma
const int sensorPin = A0;   // LM35 orta bacak (Vout) -> A0

void setup() {
  Serial.begin(9600);       // Seri Monitör: 9600 baud
}

void loop() {
  int okunan = analogRead(sensorPin);             // 0–1023
  float gerilim_mV = okunan * 5000.0 / 1024.0;    // ADC -> milivolt
  float sicaklik = gerilim_mV / 10.0;             // LM35: 10 mV/°C

  Serial.print("ADC: ");
  Serial.print(okunan);
  Serial.print("  Gerilim: ");
  Serial.print(gerilim_mV, 1);
  Serial.print(" mV  Sicaklik: ");
  Serial.print(sicaklik, 1);                      // 1 ondalık basamak
  Serial.println(" C");
  delay(1000);                                    // saniyede bir ölçüm
}

Programın çözümlemesi

  1. analogRead(A0) 0–1023 arası tam sayı döndürür.
  2. okunan * 5000.0 / 1024.0: sabitlerin .0 ile yazılması işlemin float yapılmasını sağlar.
  3. Gerilim 10'a bölünerek °C bulunur (10 mV/°C).
  4. Serial.print(sicaklik, 1) sayıyı 1 ondalık basamakla yazdırır.
int t = analogRead(A0) * 5000 / 1024 / 10; yazmak hatalıdır: UNO'da int 16 bittir (en fazla 32 767). 100 · 5000 = 500 000 olduğundan çarpım taşar ve anlamsız (hatta negatif) sonuç çıkar. Ondalık sabit (5000.0) veya float kullanın.

Gürültü azaltma: ortalama alma

LM35_Ortalama.ino
// Gürültüyü azaltmak için 10 ölçümün ortalamasını alma
const int sensorPin = A0;
const int ORNEK = 10;

void setup() {
  Serial.begin(9600);
}

float sicaklikOku() {
  long toplam = 0;                     // 10 x 1023 int'e sığar ama long güvenlidir
  for (int i = 0; i < ORNEK; i++) {
    toplam += analogRead(sensorPin);
    delay(10);
  }
  float ortalama = toplam / (float)ORNEK;  // float bölme!
  return ortalama * 5000.0 / 1024.0 / 10.0;
}

void loop() {
  float t = sicaklikOku();
  Serial.print("Ortalama sicaklik: ");
  Serial.print(t, 2);
  Serial.println(" C");
  delay(1000);
}

Tek bir ADC okuması ±1 basamak (≈ ±0,5 °C) oynayabilir. Birkaç okumanın ortalaması alınarak hem gürültü azaltılır hem de basamaklar arası değerler (örn. 24,65 °C) elde edilebilir. Simülasyon 1'de "gürültü" kutusunu işaretleyerek tek okumanın nasıl zıpladığını görün.

Seri Monitörde "°" ve Türkçe karakterler bazı terminallerde bozuk görünebildiği için çıktıda " C" ve "Sicaklik" gibi ASCII yazımlar tercih edilmiştir.

7Uygulama 2: Eşik Uyarısı ve Histerezis

Sıcaklık belirlenen bir eşiği aştığında kırmızı LED ve buzzer ile uyarı verelim. Tek bir eşik kullanılırsa, sıcaklık tam eşik civarında dalgalandığında alarm sürekli açılıp kapanır (titreşim/chattering). Bunu önlemek için iki eşik kullanılır: alarm 30 °C'de açılır, ancak sıcaklık 28 °C'nin altına inince kapanır. Aradaki 2 °C'lik banda histerezis denir (evlerdeki termostatlar da böyle çalışır).

Sicaklik_Alarm.ino
// Sıcaklık eşik uyarısı: kırmızı LED + aktif buzzer, histerezisli
const int sensorPin = A0;
const int ledPin    = 6;      // kırmızı uyarı LED'i (220 Ω ile)
const int buzzerPin = 8;      // aktif buzzer (+ ucu D8, – ucu GND)

const float ESIK_UST = 30.0;  // bu değere ulaşınca alarm AÇILIR
const float ESIK_ALT = 28.0;  // bu değerin altına inince alarm KAPANIR
bool alarm = false;           // alarmın o anki durumu

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  Serial.begin(9600);
}

float sicaklikOku() {
  int okunan = analogRead(sensorPin);
  return okunan * 5000.0 / 1024.0 / 10.0;
}

void loop() {
  float t = sicaklikOku();
  Serial.print("Sicaklik: ");
  Serial.print(t, 1);
  Serial.println(" C");

  // Histerezis: açma ve kapama için iki ayrı eşik
  if (!alarm && t >= ESIK_UST) {
    alarm = true;
    Serial.println(">>> ALARM: Sicaklik yuksek!");
  } else if (alarm && t <= ESIK_ALT) {
    alarm = false;
    Serial.println(">>> Normal seviyeye dondu.");
  }

  if (alarm) {                      // alarm varken LED ve buzzer kesikli çalışır
    digitalWrite(ledPin, HIGH);
    digitalWrite(buzzerPin, HIGH);
    delay(200);
    digitalWrite(ledPin, LOW);
    digitalWrite(buzzerPin, LOW);
    delay(200);
  } else {
    digitalWrite(ledPin, LOW);
    digitalWrite(buzzerPin, LOW);
    delay(400);
  }
}

🔬 Simülasyon 2: Histerezisli alarm

Simülasyonda ESIK_ALT'ı ESIK_UST'e eşitleyip "otomatik dalgalanma"yı açın: alarm eşik etrafında sık sık açılıp kapanır. Histerezis bandını genişlettikçe durum değişikliklerinin azaldığını gözleyin.

8Uygulama 3: Sıcaklığa Göre Renkli LED'ler

Üç LED ile basit bir sıcaklık göstergesi yapalım: < 20 °C mavi (soğuk) 20–28 °C yeşil (normal) ≥ 28 °C kırmızı + bip (sıcak). if – else if – else yapısı, aralıkların sırayla denetlenmesini ve yalnızca bir koşulun çalışmasını sağlar.

Sicaklik_Renk.ino
// Sıcaklık aralığına göre renkli LED gösterge
// < 20 °C: mavi · 20–28 °C: yeşil · ≥ 28 °C: kırmızı + bip
const int sensorPin  = A0;
const int maviLed    = 4;
const int yesilLed   = 5;
const int kirmiziLed = 6;
const int buzzerPin  = 8;     // pasif buzzer (tone ile ses)

void setup() {
  pinMode(maviLed, OUTPUT);
  pinMode(yesilLed, OUTPUT);
  pinMode(kirmiziLed, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int okunan = analogRead(sensorPin);
  float sicaklik = okunan * 5000.0 / 1024.0 / 10.0;

  // Önce tüm göstergeleri kapat
  digitalWrite(maviLed, LOW);
  digitalWrite(yesilLed, LOW);
  digitalWrite(kirmiziLed, LOW);

  if (sicaklik < 20.0) {
    digitalWrite(maviLed, HIGH);
    Serial.print("SOGUK   ");
  } else if (sicaklik < 28.0) {
    digitalWrite(yesilLed, HIGH);
    Serial.print("NORMAL  ");
  } else {
    digitalWrite(kirmiziLed, HIGH);
    tone(buzzerPin, 2000, 100);     // 2 kHz, 100 ms bip
    Serial.print("SICAK   ");
  }
  Serial.print(sicaklik, 1);
  Serial.println(" C");
  delay(500);
}

9DHT11: Sıcaklık ve Nem Sensörü

DHT11, içinde kapasitif bir nem algılayıcı ve bir NTC termistör ile bunları okuyan küçük bir mikrodenetleyici barındırır. Ölçümü kendisi yapar ve sonucu Arduino'ya tek bir veri hattı üzerinden dijital olarak gönderir; bu yüzden analogRead değil, bir kütüphane ile okunur.

Şekil 5. DHT11 (4 bacaklı çıplak sensör) bağlantısı. 3 bacaklı modüllerde pull-up direnci kart üzerindedir.
ÖzellikDHT11DHT22 (AM2302)
Besleme3,3–5,5 V3,3–6 V
Sıcaklık0…50 °C, ±2 °C, 1 °C çözünürlük−40…80 °C, ±0,5 °C
Bağıl nem%20…90, ±%5%0…100, ±%2–5
Örneklemeen fazla 1 Hz (1 s)en fazla 0,5 Hz (2 s)

Veri çerçevesi: Sensör her okumada 40 bit gönderir: nem tam kısmı (8 bit) + nem ondalık (8) + sıcaklık tam (8) + sıcaklık ondalık (8) + sağlama toplamı (8). Sağlama, ilk dört baytın toplamının son 8 bitidir; kütüphane hatalı veride NaN döndürür.

Kütüphane kurulumu

  1. Arduino IDE'de Araçlar → Kütüphaneleri Yönet… (veya sol menüde kitap simgesi) açın.
  2. Arama kutusuna DHT sensor library yazın; Adafruit tarafından yayımlanan kütüphaneyi Yükle'yin.
  3. Bağımlılık olarak Adafruit Unified Sensor kütüphanesi de istenir: Tümünü yükle'yi seçin.
  4. Programın başına #include <DHT.h> ekleyin. Örnekler: Dosya → Örnekler → DHT sensor library → DHTtester.
DHT11_Olcum.ino
// DHT11 ile sıcaklık ve bağıl nem ölçümü
// Gerekli kütüphaneler (Araçlar -> Kütüphaneleri Yönet):
//   "DHT sensor library" (Adafruit) + "Adafruit Unified Sensor"
#include <DHT.h>

#define DHTPIN  2          // DATA ucu -> D2 (10 kΩ pull-up ile)
#define DHTTYPE DHT11      // DHT22 kullanıyorsanız: DHT22

DHT dht(DHTPIN, DHTTYPE);  // sensör nesnesi

void setup() {
  Serial.begin(9600);
  Serial.println("DHT11 olcum basliyor...");
  dht.begin();
}

void loop() {
  delay(2000);                              // DHT11 en fazla 1 Hz; 2 s güvenli aralık

  float nem = dht.readHumidity();           // % bağıl nem
  float sicaklik = dht.readTemperature();   // °C (true verilirse °F)

  if (isnan(nem) || isnan(sicaklik)) {      // okuma başarısızsa NaN döner
    Serial.println("Sensor okunamadi!");
    return;                                 // loop()'un başına dön
  }

  float hissedilen = dht.computeHeatIndex(sicaklik, nem, false); // false = Celsius

  Serial.print("Nem: ");
  Serial.print(nem, 0);
  Serial.print(" %  Sicaklik: ");
  Serial.print(sicaklik, 1);
  Serial.print(" C  Hissedilen: ");
  Serial.print(hissedilen, 1);
  Serial.println(" C");
}

🔬 Simülasyon 4: DHT11 okuması ve 40 bitlik veri çerçevesi

Hissedilen sıcaklık (heat index), yüksek nemde terlemenin zorlaşmasıyla vücudun algıladığı sıcaklıktır. computeHeatIndex() ABD Ulusal Hava Servisi'nin (Rothfusz) regresyon formülünü kullanır ve özellikle 27 °C üzerinde anlamlıdır.

10TMP36 ve Sensör Karşılaştırması

TMP36 (Analog Devices) LM35 ile aynı kılıf ve aynı bacak sırasına (+Vs, Vout, GND) sahiptir; eğimi yine 10 mV/°C'dir. Farkı, çıkışa 500 mV ofset eklenmiş olmasıdır. Böylece tek beslemeyle negatif sıcaklıklar da ölçülebilir (−40 °C'de 100 mV).

T(°C) = (Vout(mV) − 500) / 10   ·   25 °C → 750 mV
TMP36_parca.ino
int okunan = analogRead(A0);
float mV = okunan * 5000.0 / 1024.0;
float sicaklik = (mV - 500.0) / 10.0;   // TMP36: 500 mV ofset

12Kendini Test Et

1) Ortam sıcaklığı 25 °C iken LM35'in çıkış gerilimi ne olur?

✓ LM35 eğimi 10 mV/°C'dir: 25 × 10 mV = 250 mV.

2) 5 V referansla analogRead(A0) = 61 okunuyorsa LM35'in ölçtüğü sıcaklık yaklaşık kaçtır?

✓ 61 · 5000 / 1024 = 297,9 mV → 297,9 / 10 ≈ 29,8 °C.

3) int t = analogRead(A0) * 5000 / 1024 / 10; satırının temel sorunu nedir?

✓ UNO'da int en fazla 32 767'dir. Örneğin 61 × 5000 = 305 000 taşar ve sonuç anlamsızdır. Ayrıca tam sayı bölme ondalığı atar.

4) DHT11 ile ilgili hangisi doğrudur?

✓ DHT11 tek hat dijital protokolle 40 bit gönderir; örnekleme hızı en fazla 1 Hz'dir. Hem sıcaklık hem nem ölçer.

5) Histerezisli bir alarmda ESIK_UST = 30 °C, ESIK_ALT = 28 °C'dir. Alarm açıkken sıcaklık 29 °C'ye düşerse ne olur?

✓ Alarm yalnızca sıcaklık 28 °C'ye (ESIK_ALT) veya altına inince kapanır. 28–30 °C bandında önceki durum korunur.

Ödev

  1. °F dönüşümü: Uygulama 1'i, sıcaklığı hem °C hem °F (F = C × 1,8 + 32) olarak yazdıracak şekilde genişletin.
  2. Min–maks kaydı: Program çalıştığı süre içinde ölçülen en düşük ve en yüksek sıcaklığı tutan ve her ölçümde bunları da yazdıran bir program yazın.
  3. Yüksek çözünürlük: analogReference(INTERNAL) kullanarak LM35'i 1,1 V referansla okuyun; 5 V referanslı sonuçlarla karşılaştırıp farkı yorumlayın.
  4. Konfor göstergesi: DHT11 ile nem %40'ın altındaysa mavi, %40–60 ise yeşil, %60'ın üzerindeyse kırmızı LED yakan programı yazın.
2. ödev için ipucu (tıklayın)
minmaks_ipucu.ino
float enDusuk = 1000.0;     // ilk ölçüm mutlaka bundan küçük olur
float enYuksek = -1000.0;   // ilk ölçüm mutlaka bundan büyük olur

void setup() { Serial.begin(9600); }

void loop() {
  float t = analogRead(A0) * 5000.0 / 1024.0 / 10.0;
  if (t < enDusuk)  enDusuk = t;
  if (t > enYuksek) enYuksek = t;
  Serial.print(t, 1);
  Serial.print("  min: ");  Serial.print(enDusuk, 1);
  Serial.print("  maks: "); Serial.println(enYuksek, 1);
  delay(1000);
}

Özet

  • LM35 analog çıkışlıdır: 10 mV/°C; bacak sırası (düz yüz önde) +Vs – Vout – GND.
  • T = analogRead · 5000 / 1024 / 10; 5 V referansta çözünürlük ≈ 0,49 °C, 1,1 V referansta ≈ 0,11 °C.
  • Hesaplarda float ve ondalıklı sabitler kullanılmalı; 16 bitlik int taşmasına dikkat edilmelidir.
  • Eşik uyarılarında histerezis (iki eşik) titreşimi önler; aralık göstergelerinde if – else if – else kullanılır.
  • DHT11 dijitaldir; Adafruit DHT sensor library Kütüphane Yöneticisi'nden kurulur, en fazla 1 Hz okunur, hatalı okuma isnan() ile yakalanır.
  • TMP36: T = (mV − 500)/10; negatif sıcaklık ölçebilir.
