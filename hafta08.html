1Sınava Hazırlık ve Hedefler

Sınavda hem hesap soruları (Ohm, Kirchhoff, gerilim bölücü, ADC) hem de kod okuma ("bu programın çıktısı nedir?") soruları beklenebilir.

  • Buton (pull-up/pull-down), LED ve LDR/potansiyometre devrelerini çizip açıklayabilmek
  • Sık yapılan donanım ve yazılım hatalarını tanıyıp düzeltebilmek

2Haftalık Özet Kartları (1–7)

1. haftaArduino ve Ohm Kanunu

  • UNO: ATmega328P, 16 MHz, 5 V; 14 dijital pin (6'sı PWM), 6 analog giriş
  • setup() bir kez, loop() sürekli çalışır
  • V = I·R; ampermetre seri, voltmetre paralel
  • LED direnci: R = (Vs − VLED) / I

2. haftaKirchhoff, gerilim bölücü, breadboard

  • KGK: kapalı çevrede gerilim artışları = düşüşleri (ΣV = 0)
  • Seri: RT = R1 + R2 + …, akım her yerde aynı
  • Bölücü: Vout = Vin · R2 / (R1 + R2)
  • Breadboard: numaralı her sıranın a–e ve f–j delikleri kendi içinde bağlı; yan raylar boyuna bağlı

3. haftaDijital yazma ve if-else

  • pinMode(p, OUTPUT) → digitalWrite(p, HIGH/LOW)
  • HIGH = 5 V, LOW = 0 V; pin başına ≤ 20 mA
  • if (koşul) {…} else {…}; karşılaştırma ==, atama =
  • Mantıksal işleçler: && (ve), || (veya), ! (değil)

4. haftaDijital okuma ve buton

  • digitalRead(p) → HIGH (1) / LOW (0)
  • Boşta kalan giriş "yüzer" → rastgele okuma; pull-up veya pull-down direnci şart
  • Pull-down (10 kΩ → GND): basınca HIGH
  • INPUT_PULLUP + buton → GND: basınca LOW

5. haftafor döngüsü

  • for (başlangıç; koşul; artırım) { … }
  • for (int i = 0; i < n; i++) → n kez çalışır (i = 0 … n−1)
  • Kayan ışık (knight rider): pin numaralarını döngü değişkeni yapma
  • Döngü değişkeni yalnızca döngü içinde geçerlidir

6. haftaAnalog okuma ve LDR

  • analogRead(A0) → 0–1023 (10 bit ADC, 0–5 V)
  • V = değer · 5,0 / 1023 (yaklaşık; teorik bölen 1024)
  • LDR: ışık ↑ → direnç ↓; sabit dirençle bölücü kurulur
  • Eşik karşılaştırması: if (deger < 300) …

7. haftaPotansiyometre

  • 3 uçlu ayarlı gerilim bölücü: dış uçlar 5 V ve GND, orta uç (silecek) A0
  • Silecek gerilimi = 5 V × konum oranı
  • Pot ile eşik/bekleme süresi ayarlama: delay(analogRead(A0))
  • Seri Monitörde okuma: Serial.begin(9600), Serial.println()

3Formül Tekrarı: Ohm, Kirchhoff ve Gerilim Bölücü

V = I · R  ·  RT = R1 + R2  ·  Vs = V1 + V2  ·  V2 = Vs · R2 / (R1 + R2)

İki seri dirençten oluşan devre hem Ohm hem Kirchhoff hem de gerilim bölücü konularının ortak örneğidir. Akım her iki dirençten de aynı geçer; gerilim dirençlerle orantılı paylaşılır. Orta noktadaki gerilimi (V2) Arduino'nun A0 girişi ile ölçersek ADC değeri de hesaplanabilir.

🔬 Simülasyon 1: Seri devre / gerilim bölücü tekrarı

Turuncu/mavi çubuk: kaynak geriliminin R1 ve R2 arasında paylaşımı (KGK). Akım arttıkça sarı çizgiler hızlanır.
Sınavda gerilim bölücü sorusunda önce hangi direncin GND tarafında olduğuna bakın: formülün payına çıkışın ölçüldüğü direnç (orta nokta ile GND arasındaki) yazılır.

5Tipik Devreler ve Tekrar Programı

Sınavda en sık çizilmesi veya yorumlanması istenen dört temel devre aşağıdadır. (b) ve (c) şemalarındaki butonlara tıklayarak pinin okuduğu değeri görebilirsiniz.

Şekil 1. (a) LED çıkışı, (b) harici pull-down dirençli buton, (c) dahili pull-up (INPUT_PULLUP) ile buton, (d) LDR gerilim bölücü. Sarı kesikli çizgiler akım yolunu gösterir.
Tekrar.ino
// TEKRAR PROGRAMI: buton, potansiyometre ve for döngüsü bir arada
// D2: buton -> GND (INPUT_PULLUP)   A0: potansiyometre orta ucu
// D3–D6: dört LED (her biri 220 Ω ile GND'ye)
const int butonPin = 2;
const int potPin = A0;

void setup() {
  pinMode(butonPin, INPUT_PULLUP);       // basılmazken HIGH, basılınca LOW
  for (int p = 3; p <= 6; p++) {         // 3, 4, 5, 6 numaralı pinleri çıkış yap
    pinMode(p, OUTPUT);
  }
  Serial.begin(9600);
}

void loop() {
  int potDeger = analogRead(potPin);     // 0–1023
  float gerilim = potDeger * 5.0 / 1023.0;
  int bekleme = 50 + potDeger / 4;       // 50–305 ms arası bekleme

  Serial.print("Pot: ");
  Serial.print(potDeger);
  Serial.print("  V = ");
  Serial.println(gerilim, 2);

  if (digitalRead(butonPin) == LOW) {    // butona basıldı mı?
    for (int p = 3; p <= 6; p++) {       // kayan ışık: 3 -> 6
      digitalWrite(p, HIGH);
      delay(bekleme);
      digitalWrite(p, LOW);
    }
  } else {
    for (int p = 3; p <= 6; p++) {       // basılmadıysa hepsini söndür
      digitalWrite(p, LOW);
    }
  }
}

Programın özellikleri

  • INPUT_PULLUP kullanıldığı için buton GND'ye bağlanır ve basılınca LOW okunur (Şekil 1c).
  • for döngüsü hem setup()'ta pinleri çıkış yapmak hem de kayan ışık için kullanılmıştır.
  • Pot değeri 0–1023 olduğundan potDeger / 4 0–255 arasıdır; bekleme 50–305 ms olur. (Tam sayı bölmesi!)
  • Butona basılı tutulduğu sürece LED'ler 3 → 6 sırasıyla kayar.
Örnek: pot = 600 → V = 600 · 5,0/1023 = 2,93 V; bekleme = 50 + 600/4 = 50 + 150 = 200 ms. Bir kayma turu 4 × 200 = 800 ms sürer.

Analog eşik göstergesi

Uc_Kademe.ino
// Gerilime göre üç kademeli gösterge (6–7. hafta tekrarı)
const int sensorPin = A0;   // LDR gerilim bölücü veya potansiyometre
const int ledDusuk = 8;
const int ledOrta = 9;
const int ledYuksek = 10;

void setup() {
  pinMode(ledDusuk, OUTPUT);
  pinMode(ledOrta, OUTPUT);
  pinMode(ledYuksek, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int deger = analogRead(sensorPin);
  Serial.println(deger);

  digitalWrite(ledDusuk, LOW);           // önce hepsini söndür
  digitalWrite(ledOrta, LOW);
  digitalWrite(ledYuksek, LOW);

  if (deger < 341) {                     // 0–340   : 0 – 1,67 V
    digitalWrite(ledDusuk, HIGH);
  } else if (deger < 682) {              // 341–681 : 1,67 – 3,33 V
    digitalWrite(ledOrta, HIGH);
  } else {                               // 682–1023: 3,33 – 5 V
    digitalWrite(ledYuksek, HIGH);
  }
  delay(200);
}

1023 / 3 ≈ 341 olduğundan aralık üç eşit parçaya bölünmüştür. if – else if – else zincirinde koşullar yukarıdan aşağıya denetlenir; ilk doğru koşulun bloğu çalışır, gerisi atlanır. Bu yüzden ikinci koşulda deger >= 341 yazmaya gerek yoktur.

8Çözümlü Örnek Sorular (15)

Her soruyu önce kâğıt üzerinde çözün, sonra Çözümü göster’e tıklayarak kontrol edin. 1–9 hesap, 10–15 kod okuma sorularıdır.

Örnek 1 – Ohm Kanunu: 9 V'luk bir pile 470 Ω direnç bağlanıyor. Devreden geçen akım kaç mA'dır?

Çözümü göster

I = V / R = 9 / 470 = 0,01915 A ≈ 19,1 mA

Örnek 2 – LED ön direnci: 5 V çıkışlı bir pine sarı LED (VLED = 2,1 V) 15 mA akımla bağlanacak. Direnç kaç Ω olmalı? 220 Ω seçilirse akım ne olur?

Çözümü göster

R = (5 − 2,1) / 0,015 = 193 Ω → standart üst değer 220 Ω. Gerçek akım: I = 2,9 / 220 = 13,2 mA (güvenli).

Örnek 3 – Seri devre: 9 V kaynağa R1 = 1 kΩ, R2 = 2,2 kΩ, R3 = 330 Ω seri bağlanmıştır. Toplam direnç, akım ve R2 üzerindeki gerilim nedir?

Çözümü göster

RT = 1000 + 2200 + 330 = 3530 Ω · I = 9 / 3530 = 2,55 mA · VR2 = 0,00255 × 2200 = 5,61 V. Kontrol (KGK): 2,55 + 5,61 + 0,84 = 9,0 V ✓

Örnek 4 – Kirchhoff Gerilim Kanunu: 12 V'luk kaynağa seri bağlı iki dirençten R1 üzerinde 4,5 V ölçülüyor ve devre akımı 3 mA'dır. R2 üzerindeki gerilim ve R1, R2 değerleri nedir?

Çözümü göster

KGK: V2 = 12 − 4,5 = 7,5 V · R1 = 4,5 / 0,003 = 1,5 kΩ · R2 = 7,5 / 0,003 = 2,5 kΩ

Örnek 5 – Gerilim bölücü: 5 V – R1 (10 kΩ) – çıkış – R2 (4,7 kΩ) – GND devresinde çıkış gerilimi nedir? Bu gerilim A0'a verilirse analogRead yaklaşık kaç okur?

Çözümü göster

Vout = 5 · 4,7 / (10 + 4,7) = 1,60 V · ADC ≈ 1,60 / 5 × 1023 ≈ 327

Örnek 6 – ADC → gerilim: analogRead(A0) = 768 okunmuştur. Pindeki gerilim yaklaşık kaç volttur?

Çözümü göster

V = 768 × 5,0 / 1023 = 3,75 V (1024'e bölünürse de 3,75 V).

Örnek 7 – LDR bölücü: 5V – LDR – A0 – 10 kΩ – GND bağlantısında LDR karanlıkta 90 kΩ, aydınlıkta 2 kΩ'dur. Her iki durumda A0 gerilimi ve ADC değeri nedir?

Çözümü göster

Karanlık: V = 5 · 10 / (90 + 10) = 0,50 V → ADC ≈ 102 · Aydınlık: V = 5 · 10 / (2 + 10) = 4,17 V → ADC ≈ 852

Örnek 8 – Potansiyometre: 10 kΩ'luk potansiyometrenin silecek ucu GND tarafından itibaren direncin %30'unda duruyor. A0'daki gerilim ve okunan değer nedir? Sonuç pot değerine bağlı mıdır?

Çözümü göster

V = 0,30 × 5 = 1,5 V → ADC ≈ 0,30 × 1023 ≈ 307. Oran korunduğu için sonuç potun toplam değerinden (1 k, 10 k, 100 k) bağımsızdır.

Örnek 9 – Güç: Örnek 2'deki 220 Ω'luk direnç üzerinde harcanan güç nedir? 1/4 W direnç yeterli midir?

Çözümü göster

P = I²·R = 0,0132² × 220 = 0,038 W ≈ 38 mW < 250 mW → yeterlidir.

Örnek 10 – Blink zamanlaması: digitalWrite(13,HIGH); delay(250); digitalWrite(13,LOW); delay(750); loop() içindeyse LED'in periyodu, frekansı ve dakikadaki yanma sayısı nedir?

Çözümü göster

T = 250 + 750 = 1000 ms → f = 1 Hz → dakikada 60 kez yanar. LED sürenin %25'inde yanıktır.

Örnek 11 – Çıktı nedir? (for): for (int i = 0; i < 10; i += 3) { Serial.print(i); Serial.print(" "); }

Çözümü göster

i = 0, 3, 6, 9 değerlerini alır; 12 < 10 yanlış olduğu için durur. Çıktı: 0 3 6 9 (4 tekrar)

Örnek 12 – Çıktı nedir? (INPUT_PULLUP): pinMode(2, INPUT_PULLUP); ve loop'ta if (digitalRead(2) == HIGH) digitalWrite(13, LOW); else digitalWrite(13, HIGH); Buton D2 ile GND arasındadır. Butona basınca LED ne yapar?

Çözümü göster

Basılınca D2 GND'ye bağlanır → LOW okunur → else çalışır → LED yanar. Bırakınca pull-up nedeniyle HIGH → LED söner.

Örnek 13 – Çıktı nedir? (tam sayı bölme): int a = 7; int b = 2; float c = a / b; Serial.println(c);

Çözümü göster

a / b iki int'in bölmesidir → 3 (ondalık atılır), sonra float'a çevrilir. println float'ı 2 basamakla yazar: 3.00. 3,5 için (float)a / b yazılmalıdır.

Örnek 14 – Çıktı nedir? (if – else if): int x = 5; if (x > 3 && x < 5) Serial.println("A"); else if (x == 5) Serial.println("B"); else Serial.println("C");

Çözümü göster

x < 5 yanlış olduğundan ilk koşul (VE) yanlıştır; ikinci koşul x == 5 doğrudur → çıktı: B

Örnek 15 – Kayan ışık süresi: for (int p = 6; p >= 2; p--) { digitalWrite(p, HIGH); delay(100); digitalWrite(p, LOW); delay(100); } Kaç LED, hangi sırayla yanar? Döngü toplam ne kadar sürer?

Çözümü göster

p = 6, 5, 4, 3, 2 → 5 LED, D6'dan D2'ye doğru. Her adım 200 ms → toplam 1000 ms = 1 s.

1) 5 V'luk bir kaynağa 1 kΩ direnç bağlanırsa akım kaç mA olur?

✓ I = 5 / 1000 = 0,005 A = 5 mA.

2) Arduino UNO'nun analog girişleri kaç bitlik ADC ile okunur ve kaç farklı değer verir?

✓ UNO'nun ADC'si 10 bittir: 2¹⁰ = 1024 değer (0–1023).

3) Bir pini giriş ya da çıkış olarak ayarlayan fonksiyon hangisidir?

✓ pinMode(pin, OUTPUT/INPUT/INPUT_PULLUP) pin yönünü belirler.

4) Voltmetre devreye nasıl bağlanır?

✓ Gerilim iki nokta arasındaki farktır; voltmetre elemana paralel bağlanır.

5) Kirchhoff Gerilim Kanunu neyi ifade eder?

✓ KGK: kaynak gerilimi, çevredeki gerilim düşümlerinin toplamına eşittir (ΣV = 0). Seçenek a Kirchhoff Akım Kanunu'dur.

6) 5 V beslemeli gerilim bölücüde R1 = R2 = 10 kΩ ise çıkış gerilimi nedir?

✓ Eşit dirençlerde gerilim yarıya bölünür: 5 · 10/(10+10) = 2,5 V.

7) Breadboard'da aynı numaralı sıradaki a, b, c, d, e delikleri için hangisi doğrudur?

✓ Her sıranın a–e grubu kendi içinde bağlıdır; ortadaki oluk a–e ile f–j gruplarını ayırır.

8) Renk bantları Kırmızı–Kırmızı–Kahverengi–Altın olan direncin değeri nedir?

✓ 2, 2, ×10¹ → 22 × 10 = 220 Ω; altın ±%5.

9) digitalRead() fonksiyonu ne döndürür?

✓ Dijital okuma yalnızca iki lojik seviye verir.

10) pinMode(2, INPUT_PULLUP) yapılmış ve buton D2 ile GND arasına bağlanmıştır. Butona basılmadığında ne okunur?

✓ Dahili pull-up direnci pini 5 V'a çeker → HIGH. Basılınca GND'ye bağlanır → LOW.

11) for (int i = 0; i < 5; i++) döngüsünün gövdesi kaç kez çalışır?

✓ i = 0, 1, 2, 3, 4 → 5 kez.

12) analogRead(A0) = 512 ise pindeki gerilim yaklaşık kaç volttur?

✓ 512 × 5 / 1023 ≈ 2,50 V.

13) Serial.begin(9600) komutundaki 9600 neyi ifade eder?

✓ 9600 baud ≈ saniyede 9600 bit; Seri Monitör de aynı hıza ayarlanmalıdır.

14) LDR'ye düşen ışık arttığında direnci nasıl değişir?

✓ Fotodirençte ışık şiddeti arttıkça serbest yük taşıyıcı artar, direnç azalır.

15) int x = 10; x = x % 4; sonrasında x kaçtır?

✓ % kalan işlecidir: 10 = 2·4 + 2 → kalan 2.

16) Butonlu bir girişte pull-up/pull-down direnci kullanılmazsa ne olur?

✓ Bağlantısız giriş, çevredeki elektriksel gürültüyü toplar; tanımsız seviye okunur.

17) Aşağıdaki programın Seri Monitör çıktısı nedir?
for (int i = 3; i > 0; i--) { Serial.print(i * 2); }

✓ i = 3, 2, 1 → 6, 4, 2 yazılır; ayraç olmadığı için yan yana: 642.

18) Kırmızı LED (2 V) 5 V'tan 10 mA ile sürülecekse gereken direnç kaç Ω'dur?

✓ R = (5 − 2) / 0,010 = 300 Ω (standart olarak 330 Ω seçilir).
Tüm soruları cevapladığınızda değerlendirme burada görünecek.

Arduino ile Programlama – Ara Sınav Formül Kağıdı (1–7. hafta)

Ohm Kanunu: V = I·R · I = V/R · R = V/I
Güç: P = V·I = I²·R = V²/R
Birimler: 1 A = 1000 mA · 1 kΩ = 1000 Ω · 1 MΩ = 10⁶ Ω · 1 s = 1000 ms
LED direnci: R = (Vs − VLED) / ILED
Kırmızı ≈ 2 V · Sarı/Yeşil ≈ 2,1–2,2 V · Mavi/Beyaz ≈ 3,2 V
Seri dirençler: RT = R1 + R2 + … (akım aynı)
Paralel (2 direnç): RT = R1·R2 / (R1 + R2) (gerilim aynı)
Kirchhoff Gerilim Kanunu: ΣV = 0 → Vs = V1 + V2 + …
Gerilim bölücü: Vout = Vin · R2 / (R1 + R2)
(R2: çıkış ile GND arasındaki direnç)
ADC (UNO): 10 bit, 0–1023, 0–5 V
değer ≈ V / 5 × 1023 · V = değer × 5,0 / 1023 · 1 basamak ≈ 4,9 mV
Renk kodu: Siyah 0 · Kahve 1 · Kırmızı 2 · Turuncu 3 · Sarı 4 · Yeşil 5 · Mavi 6 · Mor 7 · Gri 8 · Beyaz 9 · Altın ±%5 · Gümüş ±%10
Pinler: Dijital D0–D13 (D0/D1 seri) · PWM ~3, 5, 6, 9, 10, 11 · Analog A0–A5 · Pin akımı ≤ 20 mA (mutlak 40 mA)
Buton: pull-down (10 kΩ→GND) → basınca HIGH · INPUT_PULLUP (buton→GND) → basınca LOW
Blink: T = taçık + tkapalı · f = 1/T · for: for(i=0; i<n; i++) → n tekrar
Veri tipleri: int: −32768…32767 (16 bit) · float: ondalıklı · int/int → tam sayı bölme · % → kalan

1) if (sayi = 3) { … } satırında ne olur?

✓ Gönderici ve alıcı aynı hızda olmalıdır (örn. her ikisi de 9600).

✓ i = 1, 3, 5, 7, 9 → 5 kez; 11 ≤ 10 yanlış olduğu için durur.

2. ödev için ipucu (tıklayın)
buton_sayac_ipucu.ino
const int butonPin = 2;
int sayac = 0;
int oncekiDurum = HIGH;          // INPUT_PULLUP: basılı değilken HIGH

void setup() {
  pinMode(butonPin, INPUT_PULLUP);
  Serial.begin(9600);
}

void loop() {
  int durum = digitalRead(butonPin);
  if (oncekiDurum == HIGH && durum == LOW) {   // HIGH -> LOW geçişi = yeni basma
    sayac++;
    Serial.print("Basma sayisi: ");
    Serial.println(sayac);
    delay(50);                                 // buton arklarını (bounce) atlatmak için
  }
  oncekiDurum = durum;
}

Özet

  • Hesap soruları: V = I·R, R = (Vs − VLED)/I, seri RT = ΣR, KGK ΣV = 0, Vout = Vin·R2/(R1+R2).
  • ADC: 10 bit, 0–1023 ↔ 0–5 V; dönüşümde 5.0 ve float kullanılmalıdır.
  • Butonlar mutlaka pull-up veya pull-down ile kullanılır; INPUT_PULLUP'ta basılı = LOW.
  • for (i = 0; i < n; i++) n kez çalışır; if – else if – else zincirinde ilk doğru koşul çalışır.
  • En sık hatalar: = / == karışıklığı, eksik ;, eksik pinMode, tam sayı bölmesi, baud uyumsuzluğu.
