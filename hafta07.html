2Potansiyometre: Yapısı ve Çeşitleri

Potansiyometre (kısaca pot), direnci elle ayarlanabilen üç uçlu bir dirençtir. İçinde, iki ucu 1 ve 3 numaralı bacaklara bağlı yay şeklinde bir direnç izi (karbon ya da sermet) bulunur. Mile bağlı metal bir silecek (wiper) bu iz üzerinde kayar ve orta bacağa (2) bağlıdır. Mil çevrildikçe silecek konum değiştirir ve uçlar arasındaki direnç paylaşımı değişir.

Şekil 1. Potansiyometrenin iç yapısı (animasyonda silecek iz üzerinde gidip gelir), devre sembolü ve yaygın çeşitleri
Uçlar arasıDirenç
1 – 3 (dış uçlar)Her zaman toplam değer (ör. 10 kΩ), mil konumundan bağımsız
1 – 2Silecek 1'e yaklaştıkça azalır (0 → 10 kΩ)
2 – 3Silecek 3'e yaklaştıkça azalır (10 kΩ → 0)
R12 + R23= Rtoplam
  • Döner pot: mil yaklaşık 270–300° döner; ses ayarı, kontrol panelleri.
  • Sürgülü pot: doğrusal hareket; mikser masaları.
  • Trimpot: tornavida ile ayarlanır; devrede bir kez kalibrasyon için.
  • Doğrusal (B) / logaritmik (A): Arduino ile ölçüm için B tipi (doğrusal) seçilir; A tipi ses düzeyi için kullanılır. Üzerinde “B10K” yazan pot, 10 kΩ doğrusal demektir.

3Gerilim Bölücü Olarak Potansiyometre

Dış bacaklardan biri GND'ye, diğeri +5 V'a bağlandığında potansiyometre, oranı mil ile değişen bir gerilim bölücü olur. Silecek ucu (2) ile GND arasındaki gerilim, silecek konumuyla doğru orantılıdır:

Vsilecek = 5 V · R12 / (R12 + R23) = 5 V · θ / θmaks

Toplam direnç formülden sadeleşir; bu yüzden 10 kΩ yerine 1 kΩ ya da 100 kΩ pot da aynı gerilimi verir. Ancak çok küçük değerli pot fazla akım çeker (5 V / 1 kΩ = 5 mA), çok büyük değerli pot ise ADC girişinde gürültüye daha açıktır. Arduino için 10 kΩ önerilen değerdir (5 V / 10 kΩ = 0,5 mA).

4Devre Şeması: Potansiyometre, LDR ve LED

Bu haftanın tüm uygulamaları tek bir devre üzerinde yapılabilir: potansiyometre A0'a, geçen haftaki LDR gerilim bölücüsü A1'e, LED ise 220 Ω üzerinden D9'a bağlanır. (LED bar uygulaması için ayrıca D2–D7'ye 6 LED bağlanır; bağlantı 5. haftadaki gibidir.)

Şekil 2. Pot: 1 → GND, 2 (silecek) → A0, 3 → 5 V · LDR bölücü: 5 V → LDR → A1 düğümü → 10 kΩ → GND · LED: D9 → 220 Ω → LED → GND. Sarı çizgiler akımın yolunu gösterir.
Potansiyometrenin orta bacağını doğrudan 5 V veya GND'ye bağlamayın. Mil uç konuma getirildiğinde silecek ile dış uç arasındaki direnç 0 Ω'a yaklaşır ve 5 V–GND arasında kısa devre oluşur.
Mil saat yönünde çevrildiğinde değerin artması için 1 numaralı bacağı GND'ye, 3 numaralı bacağı 5 V'a bağlayın. Dış bacakların yerini değiştirmek yönü tersine çevirir; programda hiçbir değişiklik gerekmez.

5Uygulama 1: Potansiyometreyi Okuma ve Volta Çevirme (float)

Okunan ham değer (0–1023) çoğu zaman anlaşılır değildir. Bunu volta çevirmek için ondalıklı sayı türü float kullanılır. Arduino'nun resmî ReadAnalogVoltage örneğindeki gibi çarpan 5,0 / 1023,0 alınırsa 1023 değeri tam 5,00 V'a karşılık gelir.

PotOku.ino
// Potansiyometreyi okuyup ham değer, gerilim ve yüzde yazdırma
const int POT_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int deger = analogRead(POT_PIN);          // 0 ... 1023
  float volt = deger * (5.0 / 1023.0);      // 0,00 ... 5,00 V
  int yuzde = map(deger, 0, 1023, 0, 100);  // 0 ... 100

  Serial.print("Deger: ");
  Serial.print(deger);
  Serial.print("  Gerilim: ");
  Serial.print(volt);          // float varsayılan 2 basamak yazılır
  Serial.print(" V  Yuzde: %");
  Serial.println(yuzde);
  delay(200);
}

Tamsayı bölme tuzağı

İfade (deger = 614)SonuçNeden?
deger * (5 / 1023)05 / 1023 iki tamsayının bölümüdür → 0; 614 · 0 = 0
deger * 5 / 102333070 / 1023 = 3,0009 → küsurat atılır
deger * (5.0 / 1023.0)3,005.0 ondalıklı olduğu için işlem float yapılır ✓
1023 mü, 1024 mü? ADC 1024 basamaklıdır, yani her basamak 5/1024 V'tur ve ölçülebilen en büyük değer aslında 5 · 1023/1024 ≈ 4,995 V'tur. 5.0/1023.0 kullanımı, en üst değeri 5,00 V gösterir. İki yöntem arasındaki fark %0,1'den azdır; ölçüm hassasiyetinin (≈ 4,9 mV) altında kalır.

Serial.print(volt, 3) yazılırsa üç ondalık basamak gösterilir.

6map() ve constrain() Fonksiyonları

map(), bir aralıktaki değeri başka bir aralığa doğrusal olarak dönüştürür. Örneğin 0–1023 arasındaki pot değerini 50–1000 ms bekleme süresine ya da 0–100 yüzdeye çevirebiliriz.

sonuç = map(değer, girişMin, girişMaks, çıkışMin, çıkışMaks)
sonuç = (x − gmin) · (çmaks − çmin) / (gmaks − gmin) + çmin
Arduino çekirdeğindeki tanım (WMath.cpp)
long map(long x, long in_min, long in_max,
         long out_min, long out_max) {
  return (x - in_min) * (out_max - out_min)
         / (in_max - in_min) + out_min;
}
  • map() tamsayı (long) ile çalışır: bölmede küsurat atılır, yuvarlama yapılmaz.
  • Giriş aralık dışındaysa sonuç da aralık dışına çıkar; sınırlamak için constrain(x, alt, üst) kullanılır.
  • Çıkış aralığı ters verilebilir: map(x, 0, 1023, 255, 0).
ÇağrıSonuçAçıklama

map(512, 0, 1023, 50, 1000)525Bekleme süresi aralığına çevirme

7Uygulama 2: Potansiyometre ile Yanıp Sönme Hızı

Pot değerini map() ile 50–1000 ms aralığındaki bir bekleme süresine dönüştürüp LED'in yanık ve sönük kalma süresi olarak kullanıyoruz. Mil çevrildikçe LED'in yanıp sönme hızı değişir.

PotBlink.ino
// Potansiyometre ile LED yanıp sönme hızı ayarı
const int POT_PIN = A0;
const int LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int deger = analogRead(POT_PIN);              // 0 ... 1023
  int bekleme = map(deger, 0, 1023, 50, 1000);  // 50 ... 1000 ms

  Serial.print("Pot: ");
  Serial.print(deger);
  Serial.print("  Bekleme: ");
  Serial.print(bekleme);
  Serial.println(" ms");

  digitalWrite(LED_PIN, HIGH);
  delay(bekleme);
  digitalWrite(LED_PIN, LOW);
  delay(bekleme);
}
T = 2 · bekleme    f = 1000 / (2 · bekleme) Hz

🔬 Simülasyon: Pot → bekleme → LED

Program pot değerini yalnızca her döngünün başında okur. Bekleme 1000 ms iken mili çevirirseniz yeni hız en fazla 2 saniye sonra devreye girer. Simülasyon da aynı biçimde davranır. Daha hızlı tepki için ileride millis() kullanılacaktır.

8Uygulama 3: Potansiyometre ile LED Bar Göstergesi

D2–D7 pinlerine bağlı 6 LED, pot konumunu bir seviye göstergesi gibi gösterecek. Mil sıfırdayken hiçbir LED yanmaz, sona gelindiğinde 6 LED'in tamamı yanar. Burada 5. haftadaki dizi ve for döngüsü ile bu haftaki map() birlikte kullanılır.

PotBar.ino
// Potansiyometre ile 6 LED'lik bar göstergesi
const int POT_PIN = A0;
const int ledler[] = {2, 3, 4, 5, 6, 7};
const int LED_SAYISI = 6;

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < LED_SAYISI; i++) {
    pinMode(ledler[i], OUTPUT);
  }
}

void loop() {
  int deger = analogRead(POT_PIN);
  // 0..1023 -> 0..6 (7 eşit bant; 1024 ve 7 kullanıldı)
  int seviye = map(deger, 0, 1024, 0, LED_SAYISI + 1);

  for (int i = 0; i < LED_SAYISI; i++) {
    if (i < seviye) {
      digitalWrite(ledler[i], HIGH);   // seviyenin altındakiler yanar
    } else {
      digitalWrite(ledler[i], LOW);
    }
  }
  Serial.print("Deger: ");
  Serial.print(deger);
  Serial.print("  Seviye: ");
  Serial.println(seviye);
  delay(50);
}
Neden map(deger, 0, 1023, 0, 6) yazmadık? map() küsuratı attığı için 6 sonucu yalnızca deger = 1023 iken elde edilir; son LED neredeyse hiç yanmaz. map(deger, 0, 1024, 0, 7) ise 0–1023 aralığını her biri ≈ 146 birimlik 7 eşit banda böler (0, 1, …, 6).

9Uygulama 4: Potansiyometre ile LDR Eşiğini Ayarlama

Geçen haftaki gece lambasında eşik değeri programın içine sabit olarak yazılmıştı (ESIK = 300). Ortam değiştiğinde yeniden kod yüklemek gerekiyordu. Şimdi eşiği potansiyometreden okuyarak kullanıcı tarafından ayarlanabilir hâle getiriyoruz. Program iki analog girişi okur: A0 (pot = eşik) ve A1 (LDR = ışık).

AyarliGeceLambasi.ino
// Potansiyometre ile ayarlanabilir eşikli gece lambası
const int POT_PIN = A0;   // eşik ayarı
const int LDR_PIN = A1;   // ışık sensörü (5V-LDR-A1-10k-GND)
const int LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int esik = analogRead(POT_PIN);   // 0 ... 1023
  int isik = analogRead(LDR_PIN);   // 0 ... 1023

  Serial.print("Isik: ");
  Serial.print(isik);
  Serial.print("  Esik: ");
  Serial.print(esik);

  if (isik < esik) {                // ortam eşikten karanlık
    digitalWrite(LED_PIN, HIGH);
    Serial.println("  -> LED ACIK");
  } else {
    digitalWrite(LED_PIN, LOW);
    Serial.println("  -> LED KAPALI");
  }
  delay(200);
}

🔬 Simülasyon: LDR + potansiyometre

Pot tam aralığı kullanılınca çok karanlık ya da çok aydınlık eşik değerleri de seçilebilir. Ayarı daha hassas yapmak için eşiği daraltılmış bir aralığa çevirebilirsiniz: int esik = map(analogRead(A0), 0, 1023, 100, 700);

11Kendini Test Et

1) Potansiyometreyi gerilim bölücü olarak kullanırken Arduino'nun analog girişine hangi bacak bağlanır?

✓ Dış bacaklar 5 V ve GND'ye bağlanır; mil konumuna göre değişen gerilim orta bacakta (silecek) oluşur ve A0'a bağlanır.

2) map(512, 0, 1023, 0, 255) ifadesinin sonucu nedir?

✓ 512 · 255 / 1023 = 127,6; map() tamsayı aritmetiği kullandığı için küsurat atılır → 127. Yuvarlama yapılmaz.

3) int deger = 614; float volt = deger * (5 / 1023); satırından sonra volt kaç olur?

✓ Parantez içindeki 5 / 1023 iki tamsayının bölümüdür ve 0 çıkar. Doğrusu 5.0 / 1023.0 yazmaktır.

4) PotBlink.ino'da pot en uçta (deger = 1023) iken LED'in bir tam yanıp sönme periyodu kaç ms'dir?

✓ bekleme = map(1023, 0, 1023, 50, 1000) = 1000 ms. LED 1000 ms yanık + 1000 ms sönük kalır: T = 2000 ms (0,5 Hz).

5) Ayarlı gece lambasında A1'den okunan ışık 420, A0'dan okunan eşik 610 ise LED'in durumu nedir?

✓ Koşul isik < esik → 420 < 610 doğru olduğundan LED HIGH yapılır. Eşik potu yükseltildikçe lamba daha aydınlık ortamlarda da yanar.

12Ödev ve Özet

Ödev

  1. 5. haftadaki Kara Şimşek programına potansiyometre ekleyin: bekleme süresi pot ile 20–300 ms arasında ayarlansın ve her adımda yeniden okunsun.
  2. Pot değerini 0–15 aralığına çevirip 4 LED'li ikili sayıcıda gösterin; aynı anda Seri Monitör'e onluk ve ikili değeri yazdırın.
  3. Ayarlı gece lambasına geçen haftaki histerezisi ekleyin: LED, ışık (esik − 20)'nin altına inince yansın, (esik + 20)'nin üstüne çıkınca sönsün.
  4. Potu bir mod seçici olarak kullanın: değer 0–340 ise LED sürekli sönük, 341–681 ise yavaş yanıp sönsün, 682–1023 ise sürekli yanık olsun.
2. ödev için ipucu (tıklayın)

0–1023 aralığını 16 eşit banda bölmek için LED bar uygulamasındaki yöntemi kullanın: map(deger, 0, 1024, 0, 16). Sonra 5. haftadaki gibi bitRead() ile bitleri LED'lere yazın.

pot_ikili_ipucu.ino
const int bitPinleri[] = {2, 3, 4, 5};

void setup() {
  Serial.begin(9600);
  for (int b = 0; b < 4; b++) pinMode(bitPinleri[b], OUTPUT);
}

void loop() {
  int sayi = map(analogRead(A0), 0, 1024, 0, 16);   // 0 ... 15
  for (int b = 0; b < 4; b++) {
    digitalWrite(bitPinleri[b], bitRead(sayi, b));
  }
  Serial.print(sayi);
  Serial.print("  ");
  Serial.println(sayi, BIN);
  delay(100);
}

Özet

  • Potansiyometre üç uçludur: dış uçlar arası direnç sabittir, silecek (orta uç) mil ile hareket eder.
  • Dış uçlar 5 V ve GND'ye bağlanınca pot ayarlı bir gerilim bölücü olur: V = 5 · θ / θmaks; orta uç A0'a bağlanır.
  • Gerilime çevirme: float volt = deger * (5.0 / 1023.0); – tamsayı bölmeye dikkat.
  • map() doğrusal ölçekleme yapar, küsuratı atar ve sınırlamaz; gerekirse constrain() eklenir.
  • Eşit bantlar için map(deger, 0, 1024, 0, N + 1) kalıbı kullanılabilir.
  • Birden çok analog giriş (pot A0, LDR A1) aynı programda okunarak ayarlanabilir sistemler kurulur.
