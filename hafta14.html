2Kızılötesi Işık ve Spektrum

Kızılötesi (infrared, IR) ışık, dalga boyu görünür kırmızı ışıktan (≈ 700 nm) uzun, mikrodalgalardan kısa olan elektromanyetik ışınımdır. İnsan gözü IR'yi göremez; ancak sıcak olan her cisim IR yayar. Bu hafta iki farklı yaklaşım göreceğiz:

  • Aktif IR: Sistem kendi IR ışığını üretir (IR LED) ve ya karşıdaki alıcıya gönderir (kumanda) ya da yansımasını ölçer (engel sensörü). Genellikle ≈ 850–940 nm yakın IR kullanılır.
  • Pasif IR (PIR): Sensör ışık yaymaz; insan ve hayvan vücudunun yaydığı ≈ 8–14 µm termal IR'deki değişimi algılar.
Şekil 1. Elektromanyetik spektrumda kızılötesi (IR) bölge ve bu hafta kullanacağımız sensörlerin çalıştığı dalga boyları (ölçeksiz)
Kumandanın çalışıp çalışmadığını görmek için tuşa basarken IR LED'ine telefon kamerasıyla bakın: birçok kamera sensörü yakın IR'yi mor-beyaz bir parlama olarak gösterir.

3IR Alıcı Modül ve 38 kHz Taşıyıcı

Güneş ışığı, akkor lambalar ve hatta ısınmış cisimler de IR yayar. Kumanda sinyalinin bu "IR gürültüsünden" ayırt edilebilmesi için IR LED sabit yanmaz; saniyede 38 000 kez yanıp sönerek (38 kHz taşıyıcı) veri paketleri gönderir. VS1838B veya TSOP38238 gibi IR alıcı modüller yalnızca bu frekansta titreşen IR'ye tepki verir, taşıyıcıyı ayıklar ve Arduino'ya temiz bir dijital sinyal verir.

Şekil 2. IR alıcı modül (VS1838B / TSOP38238): yalnızca 38 kHz ile titreşen IR ışığına tepki verir, taşıyıcıyı ayıklar ve çıkışı aktif-düşük dijital sinyal olarak verir.

4NEC Protokolü: Bir Tuşa Basınca Ne Gönderilir?

Ucuz Arduino kumandalarının çoğu NEC protokolünü kullanır. Her tuşa basışta yaklaşık 67,5 ms süren bir çerçeve gönderilir: 9 ms başlangıç darbesi, 4,5 ms boşluk, ardından 8 bit adres, adresin tersi, 8 bit komut ve komutun tersi (toplam 32 bit). Ters baytlar hata denetimi içindir.

Şekil 3. NEC protokolünde bir çerçeve (örnek: adres 0x00, komut 0x45 – tuş "1"). Kırmızı bloklar 38 kHz'lik IR darbe paketleridir; bitler en düşük anlamlı bit (LSB) önce gönderilir.

6Devre Şeması: IR Kumanda ile LED Kontrolü

Şekil 4. IR kumanda ile LED kontrolü: VS1838B OUT → D2, VCC → 5V, GND → GND; LED'ler D5, D6, D9 (PWM) pinlerine 220 Ω ile bağlıdır. Kesikli beyaz çizgiler sinyal yönünü gösterir.
IR alıcının besleme hattına 100 Ω seri direnç ve VCC–GND arasına 4,7–10 µF kondansatör eklemek, uzun kablolarda ve gürültülü beslemede hatalı okumaları azaltır.

7Uygulama 1–2: Kodları Okuma ve LED Kontrolü

ir_kod_oku.ino
// Hafta 14 – Uygulama 1: Kumanda tuş kodlarını okuma
// Kütüphane Yöneticisi: "IRremote" (shirriff, z3t0, ArminJo) – sürüm 4.x
#include <IRremote.hpp>

const int IR_PIN = 2;     // VS1838B OUT -> D2

void setup() {
  Serial.begin(9600);
  IrReceiver.begin(IR_PIN, ENABLE_LED_FEEDBACK);  // alımda D13 LED'i yanıp söner
  Serial.println("Kumandanın bir tuşuna basın...");
}

void loop() {
  if (IrReceiver.decode()) {                       // yeni bir çerçeve çözüldü mü?
    Serial.print("Protokol: ");
    Serial.print(getProtocolString(IrReceiver.decodedIRData.protocol));
    Serial.print("  Adres: 0x");
    Serial.print(IrReceiver.decodedIRData.address, HEX);
    Serial.print("  Komut: 0x");
    Serial.print(IrReceiver.decodedIRData.command, HEX);
    if (IrReceiver.decodedIRData.flags & IRDATA_FLAGS_IS_REPEAT) {
      Serial.print("  (tekrar)");                  // tuş basılı tutuluyor
    }
    Serial.println();
    IrReceiver.resume();                           // bir sonraki kodu almaya hazırlan
  }
}
ir_led_kontrol.ino
// Hafta 14 – Uygulama 2: Kumanda ile LED kontrolü
#include <IRremote.hpp>

const int IR_PIN = 2;
const int ledPin[3] = {5, 6, 9};          // kırmızı, sarı, yeşil (PWM pinleri)
bool durum[3] = {false, false, false};    // LED'ler açık mı?
int parlaklik = 255;                      // ortak parlaklık (0–255)

void ledleriGuncelle() {
  for (int i = 0; i < 3; i++) {
    analogWrite(ledPin[i], durum[i] ? parlaklik : 0);
  }
}

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < 3; i++) pinMode(ledPin[i], OUTPUT);
  IrReceiver.begin(IR_PIN, ENABLE_LED_FEEDBACK);
}

void loop() {
  if (IrReceiver.decode()) {
    uint8_t komut = IrReceiver.decodedIRData.command;
    bool tekrar = IrReceiver.decodedIRData.flags & IRDATA_FLAGS_IS_REPEAT;
    IrReceiver.resume();

    if (!tekrar) {                         // aç/kapa tuşları tekrar çerçevelerini yok sayar
      switch (komut) {
        case 0x45: durum[0] = !durum[0]; break;                    // tuş 1
        case 0x46: durum[1] = !durum[1]; break;                    // tuş 2
        case 0x47: durum[2] = !durum[2]; break;                    // tuş 3
        case 0x19: durum[0] = durum[1] = durum[2] = false; break;  // tuş 0
        case 0x0D: durum[0] = durum[1] = durum[2] = true; break;   // tuş #
      }
    }
    if (komut == 0x18) parlaklik = min(255, parlaklik + 15);   // YUKARI (basılı tutulabilir)
    if (komut == 0x52) parlaklik = max(15, parlaklik - 15);    // AŞAĞI

    ledleriGuncelle();
    Serial.print("Komut: 0x");
    Serial.print(komut, HEX);
    Serial.print(tekrar ? " (tekrar)" : "");
    Serial.print("  LED: ");
    for (int i = 0; i < 3; i++) Serial.print(durum[i] ? "1" : "0");
    Serial.print("  Parlaklık: ");
    Serial.println(parlaklik);
  }
}

8IR Engel Sensörü (Aktif IR)

IR engel (yansıma) sensörü modülünde yan yana bir IR LED ve bir fotodiyot bulunur. LED'in yaydığı IR ışık önündeki bir cisimden yansıyıp fotodiyota ulaşırsa fotodiyottaki gerilim değişir. LM393 karşılaştırıcısı bu gerilimi potansiyometreyle ayarlanan eşikle karşılaştırır ve OUT pinini LOW yapar (aktif-düşük). Kart üzerindeki ikinci LED de bu sırada yanar.

Şekil 5. IR engel sensörü: IR LED'in ışığı engelden yansıyıp fotodiyota ulaşırsa OUT pini LOW olur.
ÖzellikDeğer (FC-51 tipi)
Besleme3,3–5 V
Algılama mesafesi≈ 2–30 cm (pot ile ayarlı, yüzeye bağlı)
ÇıkışDijital: engel varken LOW, yokken HIGH
Açı≈ 35°

Nerelerde kullanılır? Engelden kaçan robotlar, çizgi izleyen robotlar (TCRT5000 ile siyah/beyaz zemin ayrımı), ürün sayma, dokunmasız butonlar.

Mesafe ölçmez, yalnızca eşik altında engel olup olmadığını söyler. Mesafe için 11. haftadaki ultrasonik sensörü kullanın.

Güneş ışığı güçlü IR içerdiğinden açık havada veya pencere önünde modül sürekli "engel var" verebilir. Siyah ve mat yüzeyler IR'yi soğurduğundan çok yakından bile algılanmayabilir.
ir_engel.ino
// Hafta 14 – Uygulama 3: IR engel sensörü ile uyarı
const int engelPin = 8;     // modül OUT
const int ledPin = 13;      // kart üzerindeki L LED'i
const int buzzerPin = 12;
bool oncekiEngel = false;

void setup() {
  Serial.begin(9600);
  pinMode(engelPin, INPUT);
  pinMode(ledPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  bool engel = (digitalRead(engelPin) == LOW);   // LOW = engel VAR (aktif-düşük)
  digitalWrite(ledPin, engel ? HIGH : LOW);
  if (engel) tone(buzzerPin, 1500);
  else noTone(buzzerPin);

  if (engel != oncekiEngel) {                    // yalnızca durum değişince yaz
    Serial.println(engel ? "Engel VAR" : "Engel YOK");
    oncekiEngel = engel;
  }
  delay(20);
}

9PIR Hareket Sensörü HC-SR501 (Pasif IR)

PIR (Passive Infrared) sensörün kalbinde iki parçalı bir piroelektrik eleman vardır: üzerine düşen IR ışınımı değiştiğinde küçük bir gerilim üretir. Önündeki beyaz kubbe bir Fresnel lensidir; algılama alanını birçok bölgeye böler ve IR'yi elemana odaklar. Sıcak bir cisim (insan) bir bölgeden diğerine geçtiğinde iki yarının çıkışı farklılaşır ve modül OUT pinini belirli bir süre HIGH (≈ 3,3 V) yapar. Sabit duran bir kişi veya sabit sıcaklıktaki bir cisim algılanmaz: PIR değişimi algılar.

Şekil 6. PIR sensörü kendisi ışık yaymaz (pasif); ortamdaki IR ışınımının değişimini algılar.
Özellik / AyarHC-SR501
Besleme4,5–20 V (UNO'da 5V); çıkış HIGH ≈ 3,3 V (Arduino için yeterli)
Algılama≈ 3–7 m, ≈ 110° koni
Sx (zaman) potansiyometresiOUT'un HIGH kalma süresi ≈ 3 s – 5 dk
Sx (hassasiyet) potansiyometresialgılama mesafesi
Jumper H (tekrar tetikleme)hareket sürdükçe süre yeniden başlar, OUT HIGH kalır
Jumper L (tek tetikleme)süre dolunca OUT LOW olur, ≈ 2,5 s kilitli kalır, sonra yeniden tetiklenir
Isınma süresienerji verildikten sonra ≈ 30–60 s kararsız çıkış
pir_hareket.ino
// Hafta 14 – Uygulama 4: PIR ile hareket algılama
const int pirPin = 7;       // HC-SR501 OUT
const int ledPin = 13;
int oncekiDurum = LOW;
unsigned long sayac = 0;

void setup() {
  Serial.begin(9600);
  pinMode(pirPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.println("PIR ısınıyor (30 s)...");
  delay(30000);              // sensörün ortama alışması için bekle
  Serial.println("Hazır.");
}

void loop() {
  int durum = digitalRead(pirPin);
  digitalWrite(ledPin, durum);

  if (durum == HIGH && oncekiDurum == LOW) {        // yükselen kenar: hareket başladı
    sayac++;
    Serial.print("Hareket algılandı! #");
    Serial.println(sayac);
  } else if (durum == LOW && oncekiDurum == HIGH) { // düşen kenar
    Serial.println("Hareket bitti.");
  }
  oncekiDurum = durum;
  delay(50);
}

12Kendini Test Et

Doğru seçeneği bulduğunuzda kısa bir açıklama görüntülenir.

1) TV kumandaları ve IR engel sensörleri genellikle hangi dalga boyunda çalışır?

✓ Kumanda LED'leri ve engel sensörleri ≈ 850–940 nm yakın IR kullanır; ≈ 10 µm vücut ısısıdır (PIR).

2) VS1838B IR alıcının OUT pini, 38 kHz'lik IR sinyali alırken hangi seviyededir?

✓ Alıcı taşıyıcıyı demodüle eder; çıkış aktif-düşüktür, yani IR paketi geldiği sürece LOW olur.

3) IrReceiver.resume() çağrılmazsa ne olur?

✓ decode() sonrası alıcı tamponu kilitli kalır; resume() bir sonraki çerçeveyi almak için alıcıyı yeniden etkinleştirir.

4) IR engel sensörünün önüne mat siyah bir kutu konduğunda OUT çoğunlukla nedir?

✓ Siyah mat yüzey IR'yi soğurur, fotodiyota yeterli yansıma ulaşmaz; OUT HIGH kalır ve engel algılanmaz.

5) PIR sensörü neden 'pasif' olarak adlandırılır?

✓ PIR ışık kaynağı içermez; insan vücudunun yaydığı termal IR'deki değişimi piroelektrik elemanla algılar.

13Ödev ve Özet

Ödev

  1. Kumandanın ◀ ve ▶ tuşlarıyla 12. haftadaki servoyu 10'ar derece döndüren bir program yazın (IRremote Timer2, Servo.h Timer1 kullandığı için birlikte çalışırlar).
  2. Kumandayla 4 haneli şifre girilen, doğru şifrede yeşil LED'i yakan, yanlışta buzzer çalan bir kapı kilidi yapın (girilen haneleri LCD'de * olarak gösterin).
  3. PIR ve LDR'yi birleştirerek yalnızca karanlıkta ve hareket olduğunda 20 saniye yanan bir koridor lambası tasarlayın.
  4. IR engel sensörüyle önünden geçen nesneleri sayan bir "bant sayacı" yapın; sayıyı LCD'de gösterin, kumandanın 0 tuşuyla sıfırlayın.

Özet

  • IR, görünür kırmızıdan uzun dalga boylu ışınımdır; kumanda/engel sensörleri ≈ 940 nm yakın IR, PIR ≈ 10 µm termal IR ile çalışır.
  • IR alıcılar 38 kHz taşıyıcıyı ayıklar; çıkış aktif-düşüktür. Yaygın kumandalar NEC protokolü (adres + komut, 32 bit) kullanır.
  • IRremote v4: IrReceiver.begin() → decode() → decodedIRData.command → resume(); Timer2 kullanır.
  • IR engel modülü: engel varken OUT = LOW; mesafe ölçmez, yüzey rengine ve ortam ışığına duyarlıdır.
  • PIR (HC-SR501): harekette OUT = HIGH; süre ve hassasiyet potansiyometreleri, H/L tetikleme modu ve ısınma süresi vardır.
  • Dönem sonu projesi: Algıla → Karar ver → Uygula; parçaları ayrı test edip birleştirin.
