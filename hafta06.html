2Analog ve Dijital Sinyal

Şimdiye kadar kullandığımız digitalRead() ve digitalWrite() yalnızca iki durumla çalışıyordu: LOW (0 V) ve HIGH (5 V). Oysa doğadaki büyüklüklerin çoğu (sıcaklık, ışık şiddeti, ses, basınç) sürekli değişir ve iki değerle ifade edilemez. Bu tür büyüklükleri temsil eden sinyallere analog sinyal denir.

3ADC: Analog-Dijital Dönüştürücü ve Çözünürlük

Mikrodenetleyici yalnızca sayılarla çalışabildiği için analog gerilimi bir sayıya çevirmesi gerekir. Bu işi yapan birime ADC (Analog-to-Digital Converter) denir. ATmega328P'de 10 bitlik bir ADC bulunur ve 6 analog giriş (A0–A5) bu tek ADC'yi sırayla paylaşır.

210 = 1024 seviye  →  0 … 1023
Çözünürlük = 5 V / 1024 ≈ 4,88 mV
N = ⌊ Vgiriş · 1024 / 5 ⌋    V ≈ N · 5 / 1024

Yani okunan değer 1 arttığında giriş gerilimi yaklaşık 4,9 mV artmıştır. 4,9 mV'tan küçük değişimler ADC tarafından ayırt edilemez; bu sınırlamaya nicemleme (kuantalama) hatası denir.

4analogRead() ve Seri Haberleşme: Seri Monitör ve Seri Çizici

analogRead(pin), verilen analog pindeki gerilimi okuyup 0–1023 arasında bir int değer döndürür. Analog pinler varsayılan olarak giriştir; bu nedenle pinMode() ile ayarlamaya gerek yoktur. Okunan değeri görmek için seri haberleşme kullanılır: Arduino, USB kablosu üzerinden bilgisayara metin gönderir.

  1. setup() içinde Serial.begin(9600); yazılır. 9600, saniyedeki bit sayısıdır (baud hızı).
  2. Kod yüklendikten sonra IDE'de Araçlar → Seri Port Ekranı (veya sağ üstteki büyüteç simgesi, Ctrl+Shift+M) açılır.
  3. Seri Monitör'ün sağ altındaki baud hızı da 9600 seçilmelidir; aksi hâlde anlamsız karakterler görülür.
  4. Değerleri grafik olarak görmek için Araçlar → Seri Çizici (Serial Plotter, Ctrl+Shift+L) açılır. Seri Monitör ile Seri Çizici aynı anda açılamaz; biri kapatılmalıdır.

5Fotosensör: LDR (Işığa Bağımlı Direnç)

LDR (Light Dependent Resistor) ya da fotodirenç, direnci üzerine düşen ışık şiddetine göre değişen pasif bir elemandır. Yüzeyindeki zikzak şeklindeki iz kadmiyum sülfür (CdS) adlı yarı iletken malzemeden yapılır. Işık fotonları bu malzemedeki elektronlara enerji verir; serbest kalan yük taşıyıcıları arttıkça direnç azalır.

Şekil 3. LDR'nin yapısı ve tipik direnç–aydınlık eğrisi (GL5528 benzeri bir LDR için yaklaşık değerler)

Nerelerde kullanılır?

  • Sokak lambalarının otomatik açılması
  • Telefon ekranı parlaklık ayarı
  • Gece lambası, alarm (ışık kesilince uyarı)
  • Güneş takip sistemleri
Arduino doğrudan direnç ölçemez, yalnızca gerilim ölçebilir. Bu yüzden LDR'nin direnç değişimini bir gerilim değişimine çevirmemiz gerekir: gerilim bölücü.

6LDR ile Gerilim Bölücü

2. haftada gördüğümüz gerilim bölücüde, seri bağlı iki direncin ortak noktasındaki gerilim, dirençlerin oranına bağlıdır. LDR'yi üst (+5 V tarafı), 10 kΩ'luk sabit direnci alt (GND tarafı) kola yerleştirip orta noktayı A0'a bağlarız:

VA0 = 5 V · Rsabit / (RLDR + Rsabit) = 5 · 10 kΩ / (RLDR + 10 kΩ)
OrtamRLDRVçıkış (A0)analogRead()
Zifiri karanlık (≈1 MΩ)1 MΩ0,05 V10
Gece (0,1 lx)240 kΩ0,20 V40
Çok loş (1 lx)60 kΩ0,71 V146
Loş oda (10 lx)15 kΩ2,00 V409
Aydınlık oda (100 lx)4 kΩ3,62 V742

Çözümlü örnek

Loş bir odada RLDR = 15 kΩ olsun:

VA0 = 5 · 10 / (15 + 10) = 2,00 V

analogRead = ⌊2,00 · 1024 / 5⌋ = 409

Bu bağlantıda ışık arttıkça okunan değer artar. LDR ile 10 kΩ'un yerleri değiştirilirse ilişki tersine döner: ışık arttıkça değer azalır. Programdaki if koşulunu bağlantıya göre yazmalısınız.

Sabit direnç olarak 10 kΩ seçilmesinin nedeni, LDR'nin oda ışığındaki direncine (10–20 kΩ) yakın olmasıdır. Bu sayede en çok kullanılan ortamlarda çıkış gerilimi ölçeğin ortasında kalır ve hassasiyet en yüksek olur.

8Uygulama 1: Işık Ölçer ve Seri Çizici

İlk programda LDR değerini okuyup Seri Monitör'e yazdırıyoruz. Elinizle LDR'nin üzerini kapatıp açtığınızda değerin nasıl değiştiğini gözlemleyin; bu gözlem gece lambası için eşik değeri seçerken kullanılacaktır.

IsikOlcer.ino
// LDR ile ışık seviyesi ölçme
const int LDR_PIN = A0;      // gerilim bölücünün orta noktası

void setup() {
  Serial.begin(9600);        // Seri Monitör: 9600 baud
}

void loop() {
  int isik = analogRead(LDR_PIN);   // 0 (karanlık) ... 1023 (aydınlık)
  Serial.println(isik);             // değeri yazdır, alt satıra geç
  delay(200);                       // saniyede 5 ölçüm
}
IsikCizici.ino (Seri Çizici için)
// Seri Çizici'de iki çizgi: ışık değeri ve sabit eşik
const int LDR_PIN = A0;
const int ESIK = 300;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int isik = analogRead(LDR_PIN);
  Serial.print("Isik:");     // etiket:değer biçimi
  Serial.print(isik);
  Serial.print(",");         // çizgileri virgül ayırır
  Serial.print("Esik:");
  Serial.println(ESIK);      // satır sonu = bir zaman noktası
  delay(50);
}
Seri Monitör'de görülen değerler ölçümden ölçüme ±1–3 birim oynayabilir. Bu, ADC'nin nicemleme hatası ve ortamdaki elektriksel gürültüden kaynaklanır ve normaldir. Floresan lambalar altında 50 Hz'lik titreşim nedeniyle oynama daha belirgin olabilir.

9Uygulama 2: Otomatik Gece Lambası

Ortam karardığında LED'i kendiliğinden yakan bir gece lambası yapacağız. Önceki uygulamada odanızın karanlık ve aydınlık değerlerini not edin; eşik değeri bu ikisinin arasında seçilir. Okunan değer eşiğin altına düştüğünde if koşulu doğru olur ve LED yanar.

GeceLambasi.ino
// LDR ile otomatik gece lambası
const int LDR_PIN = A0;
const int LED_PIN = 9;
const int ESIK = 300;   // bu değerin altı "karanlık" kabul edilir

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int isik = analogRead(LDR_PIN);   // ışık seviyesini oku

  Serial.print("LDR = ");
  Serial.print(isik);

  if (isik < ESIK) {                // karanlık mı?
    digitalWrite(LED_PIN, HIGH);    // evet: LED'i yak
    Serial.println("  -> LED ACIK");
  } else {
    digitalWrite(LED_PIN, LOW);     // hayır: LED'i söndür
    Serial.println("  -> LED KAPALI");
  }
  delay(500);
}
Şekil 5. Gece lambası programının akış diyagramı
İleri düzey: Histerezis ile titremeyi önleme (tıklayın)

Işık seviyesi tam eşik değerinin çevresinde olduğunda gürültü nedeniyle okunan değer 299–301 arasında gidip gelir ve LED titrer. Çözüm, açma ve kapama için iki ayrı eşik kullanmaktır (histerezis): LED 280'in altında yanar, ancak 320'nin üzerine çıkınca söner.

GeceLambasiHisterezis.ino
const int LDR_PIN = A0;
const int LED_PIN = 9;
const int ACMA_ESIGI = 280;     // bunun altında LED yanar
const int KAPAMA_ESIGI = 320;   // bunun üstünde LED söner
bool ledAcik = false;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int isik = analogRead(LDR_PIN);
  if (!ledAcik && isik < ACMA_ESIGI) {
    ledAcik = true;
  } else if (ledAcik && isik > KAPAMA_ESIGI) {
    ledAcik = false;
  }
  // 280-320 arasında önceki durum korunur
  digitalWrite(LED_PIN, ledAcik ? HIGH : LOW);
  delay(100);
}

11Kendini Test Et

1) Arduino UNO'nun 10 bitlik ADC'si kaç farklı değer üretebilir?

✓ 210 = 1024 farklı değer: 0'dan 1023'e kadar. 256 (28) analogWrite'ın aralığıdır.

2) analogRead() 512 değerini döndürdüyse A0 pinindeki gerilim yaklaşık kaç volttur?

✓ V ≈ N · 5 / 1024 = 512 · 5 / 1024 = 2,5 V.

3) Ortam karardığında LDR'nin direnci nasıl değişir?

✓ Işık azalınca CdS içindeki serbest yük taşıyıcıları azalır, direnç artar. Tam karanlıkta ≥ 1 MΩ olur.

4) 5 V → LDR → A0 → 10 kΩ → GND bağlantısında RLDR = 40 kΩ ise analogRead() yaklaşık kaç okur?

✓ V = 5 · 10 / (40 + 10) = 1,0 V; N = ⌊1,0 · 1024 / 5⌋ = 204.

5) Seri Monitör'de anlamsız karakterler (ör. ⸮⸮x) görülüyorsa en olası neden nedir?

✓ Gönderen ve alan taraf aynı baud hızında olmalıdır. Serial.begin(9600) kullanıldıysa Seri Monitör de 9600 baud seçilmelidir. LDR'nin zaten kutbu yoktur.

12Ödev ve Özet

Ödev

  1. LDR ile 10 kΩ'un yerlerini değiştirin (10 kΩ üstte, LDR altta). Karanlık ve aydınlıkta okunan değerleri tablo hâlinde kaydedin ve GeceLambasi.ino'daki if koşulunu bu yeni bağlantıya göre düzenleyin.
  2. 3 LED (kırmızı, sarı, yeşil) kullanarak ışık seviyesini karanlık / loş / aydınlık olarak gösteren bir program yazın (if – else if – else).
  3. IsikCizici.ino'yu çalıştırıp Seri Çizici'de elinizle LDR'yi yavaşça kapatın. Ekran görüntüsünü alarak eşik çizgisinin kesildiği anları işaretleyin.
  4. Kalibrasyon: Programın ilk 5 saniyesinde ölçülen en küçük ve en büyük değeri bulup eşiği bu ikisinin ortalaması olarak otomatik belirleyen bir gece lambası yazın.
2. ödev için ipucu (tıklayın)
uc_seviye_ipucu.ino
const int KIRMIZI = 4, SARI = 5, YESIL = 6;

void setup() {
  pinMode(KIRMIZI, OUTPUT);
  pinMode(SARI, OUTPUT);
  pinMode(YESIL, OUTPUT);
}

void loop() {
  int isik = analogRead(A0);
  digitalWrite(KIRMIZI, LOW);
  digitalWrite(SARI, LOW);
  digitalWrite(YESIL, LOW);
  if (isik < 300) {
    digitalWrite(KIRMIZI, HIGH);      // karanlık
  } else if (isik < 700) {
    digitalWrite(SARI, HIGH);         // loş
  } else {
    digitalWrite(YESIL, HIGH);        // aydınlık
  }
  delay(200);
}

Özet

  • Analog sinyal sürekli, dijital sinyal iki seviyelidir; analog girişler A0–A5'tir.
  • UNO'nun ADC'si 10 bittir: 0–1023 arası 1024 seviye, çözünürlük 5 V / 1024 ≈ 4,88 mV.
  • analogRead() pinMode gerektirmez; değeri Serial.println() ile Seri Monitör'de, “etiket:değer” biçimiyle Seri Çizici'de izleriz.
  • LDR'nin direnci ışıkla azalır (karanlıkta ≥ 1 MΩ, oda ışığında 10–20 kΩ).
  • Arduino direnç değil gerilim ölçer; LDR + 10 kΩ gerilim bölücü: VA0 = 5 · 10k / (RLDR + 10k).
  • Gece lambası: if (isik < ESIK) LED yanar; eşik çevresindeki titreşim histerezis ile önlenir.
