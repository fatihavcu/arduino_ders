2Neden Döngü? for Döngüsünün Sözdizimi

8 LED'i sırayla yakmak istediğimizi düşünelim. Döngü bilmeden her LED için ayrı satır yazmamız gerekir. Bu hem uzun hem de hataya açık bir yöntemdir; LED sayısı 20 olsaydı 20 satır pinMode yazmak gerekirdi.

uzun_yol.ino (döngüsüz)
void setup() {
  pinMode(2, OUTPUT);
  pinMode(3, OUTPUT);
  pinMode(4, OUTPUT);
  pinMode(5, OUTPUT);
  pinMode(6, OUTPUT);
  pinMode(7, OUTPUT);
  pinMode(8, OUTPUT);
  pinMode(9, OUTPUT);
}
void loop() { }
kisa_yol.ino (for ile)
void setup() {
  // pin = 2, 3, 4, ... , 9 değerlerini sırayla alır
  for (int pin = 2; pin <= 9; pin++) {
    pinMode(pin, OUTPUT);
  }
}
void loop() { }

İki program aynı işi yapar. Sağdaki sürümde LED sayısını değiştirmek için yalnızca 9 sayısını değiştirmek yeterlidir.

3for Döngüsünün Akış Diyagramı ve Adım Adım Çalışması

Aşağıdaki akış diyagramında for döngüsünün çalışma sırası görülmektedir: ① → ② → ③ → ④ → ② → ③ → ④ → … → ② → ⑤. Başlangıç bölümü yalnızca bir kez çalışır; koşul ise her turda yeniden kontrol edilir. Koşul ilk kez yanlış olduğunda program döngüden çıkar ve döngüden sonraki satıra geçer.

🔬 Simülasyon: for döngüsünü adım adım çalıştırın

adim_adim.ino
const int N = 3;   // simülasyonda kaydırıcı ile değiştirilir

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < N; i++) {
    Serial.print("i = ");
    Serial.println(i);
  }
  Serial.println("Dongu bitti");
}
void loop() { }
Şekil 1. for döngüsünün akış diyagramı. Simülasyonda çalışan bölüm turuncu çerçeveyle gösterilir.
Sayaç değişkeni i döngünün başlangıç bölümünde tanımlandığı için yalnızca döngü içinde geçerlidir (yerel değişken). Döngü bittikten sonra i'yi kullanmaya çalışırsanız derleyici 'i' was not declared in this scope hatası verir.

4while ve do-while Döngüleri (Kısaca)

Tekrar sayısının önceden bilinmediği durumlarda while döngüsü tercih edilir. while, koşul doğru olduğu sürece gövdeyi tekrarlar. for döngüsündeki başlangıç ve artırma işlemleri burada programcı tarafından ayrıca yazılır.

while_ornek.ino
void setup() {
  Serial.begin(9600);
  int i = 0;              // başlangıç (döngüden önce)
  while (i < 5) {         // koşul
    Serial.println(i);    // gövde
    i++;                  // artırma (unutulmamalı!)
  }
}
void loop() { }
dowhile_ornek.ino
void setup() {
  Serial.begin(9600);
  int i = 10;
  do {
    Serial.println(i);    // koşul yanlış olsa da
    i++;                  // gövde EN AZ BİR KEZ çalışır
  } while (i < 5);
}
void loop() { }
DöngüKoşul kontrolüEn az kaç kez çalışır?Tipik kullanım
forTur başında0Tekrar sayısı belli (8 LED, 16 sayı…)
whileTur başında0Bir olay gerçekleşene kadar bekleme (ör. buton basılana kadar)
do-whileTur sonunda1Önce işlem yapılıp sonra kontrol edilecekse

Örnek: 4. haftadaki butonu kullanarak, buton basılana kadar programı bekletmek için while (digitalRead(7) == LOW) { } yazılabilir. Gövde boştur; döngü yalnızca koşulu tekrar tekrar kontrol eder.

Sonsuz döngü: while içinde koşulu değiştiren bir komut yoksa (örneğin i++ unutulursa) koşul hiçbir zaman yanlış olmaz ve program o noktada sonsuza kadar takılır. Arduino'da loop() zaten sonsuz bir döngüdür; onun içinde ayrıca sonsuz döngü kurmaya genellikle gerek yoktur.

5Diziler (Array) ile Pin Yönetimi

Dizi, aynı türden birden çok değeri tek bir isim altında saklayan veri yapısıdır. Elemanlara köşeli parantez içindeki indis ile erişilir. LED'ler ardışık pinlere bağlı olmasa bile (ör. 3, 5, 6, 9, 10, 11) pin numaralarını bir diziye yazıp döngüyle kolayca kullanabiliriz.

Şekil 2. ledler dizisi: her kutuda bir pin numarası, altında indisi
dizi_tanim.ino
// Tanımlama yöntemleri
int ledler[] = {2, 3, 4, 5, 6, 7, 8, 9};   // boyutu derleyici sayar (8)
int sayilar[4];                             // 4 elemanlı, değerleri sonradan atanır
const int LED_SAYISI = sizeof(ledler) / sizeof(ledler[0]);  // 16 bayt / 2 bayt = 8

void setup() {
  for (int i = 0; i < LED_SAYISI; i++) {
    pinMode(ledler[i], OUTPUT);   // i = 0 iken ledler[0] = 2 numaralı pin
  }
  sayilar[0] = 25;                // ilk elemana değer atama
}
void loop() { }
İfadeDeğerAçıklama
ledler[0]2İlk eleman (indis 0)
ledler[7]9Son eleman (indis = eleman sayısı − 1)

ledler[8] yazmak 8 elemanlı dizinin dışına taşmaktır. Derleyici bu hatayı genellikle yakalamaz; program bellekteki rastgele bir değeri pin numarası sanarak beklenmedik davranır. Döngü koşulunu i < 8 şeklinde yazın, i <= 8 değil.

6Devre Şeması: 8 LED'li Bağlantı

Her LED, kendi dijital pinine 220 Ω'luk bir ön dirençle bağlanır; LED'lerin katotları (kısa bacak) breadboard'un GND (–) hattında birleşir ve bu hat Arduino'nun GND pinine bağlanır. Pin HIGH olduğunda akım pin → direnç → LED → GND yolunu izler.

Şekil 3. D2–D9 pinlerine bağlı 8 LED. Animasyonda Kara Şimşek programı çalışmaktadır; yalnızca HIGH olan pinin hattında akım (sarı çizgi) akar.

Akım hesabı (1. hafta tekrarı)

Kırmızı LED için VLED ≈ 2 V: I = (5 − 2) / 220 ≈ 13,6 mA. Bu değer pin başına önerilen 20 mA sınırının altındadır.

Toplam akım sınırı

ATmega328P'nin toplam G/Ç akımı (VCC/GND pinleri üzerinden) 200 mA ile sınırlıdır. 8 LED aynı anda yanarsa ≈ 8 × 13,6 ≈ 109 mA çekilir; bu güvenli bölgededir.

Bağlantı yaparken önce tüm LED'lerin uzun bacağını (anot) direnç tarafına, kısa bacağını GND hattına yerleştirin. Bir LED yanmıyorsa ilk kontrol edilecek şey ters takılıp takılmadığıdır.

7Uygulama 1–2: Yürüyen Işık ve Kara Şimşek

Yürüyen ışık uygulamasında LED'ler soldan sağa sırayla yanar; aynı anda yalnızca bir LED yanıktır. Kara Şimşek (Knight Rider) etkisinde ise ışık bir uçtan diğerine gidip geri döner. Geri dönüşte uçlardaki LED'lerin iki kez yanıp duraklama yapmaması için ikinci döngü LED_SAYISI − 2'den başlayıp 1'de biter.

YuruyenIsik.ino
// 8 LED ile yürüyen ışık (soldan sağa)
const int ledler[] = {2, 3, 4, 5, 6, 7, 8, 9};
const int LED_SAYISI = 8;
int bekleme = 100;   // her LED'in yanık kalma süresi (ms)

void setup() {
  for (int i = 0; i < LED_SAYISI; i++) {
    pinMode(ledler[i], OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < LED_SAYISI; i++) {
    digitalWrite(ledler[i], HIGH);  // i. LED'i yak
    delay(bekleme);                 // bekle
    digitalWrite(ledler[i], LOW);   // söndür, sıradakine geç
  }
}
KaraSimsek.ino
// 8 LED ile Kara Şimşek (git-gel ışık)
const int ledler[] = {2, 3, 4, 5, 6, 7, 8, 9};
const int LED_SAYISI = 8;
int bekleme = 80;

void setup() {
  for (int i = 0; i < LED_SAYISI; i++) {
    pinMode(ledler[i], OUTPUT);
  }
}

void loop() {
  // İleri: indis 0, 1, ..., 7
  for (int i = 0; i < LED_SAYISI; i++) {
    digitalWrite(ledler[i], HIGH);
    delay(bekleme);
    digitalWrite(ledler[i], LOW);
  }
  // Geri: indis 6, 5, ..., 1 (uçlar tekrar yanmasın)
  for (int i = LED_SAYISI - 2; i > 0; i--) {
    digitalWrite(ledler[i], HIGH);
    delay(bekleme);
    digitalWrite(ledler[i], LOW);
  }
}

Kara Şimşek'te bir tam tur: ileri döngü 8 adım + geri döngü 6 adım = 14 adım. Her adım bekleme kadar sürdüğünden bir tur süresi 14 × 80 = 1120 ms olur.

9Uygulama 3: LED Bar ile Sayma

LED bar (çubuk gösterge) uygulamasında LED'ler söndürülmeden birer birer yakılır; böylece yanan LED sayısı 1'den 8'e kadar artar. Ardından ters yönde birer birer söndürülür. Bu yapı ilerleyen haftalarda bir sensör değerini (ışık şiddeti, potansiyometre konumu) göstermek için kullanılacaktır.

LedBar.ino
const int ledler[] = {2, 3, 4, 5, 6, 7, 8, 9};
const int LED_SAYISI = 8;
int bekleme = 150;

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < LED_SAYISI; i++) {
    pinMode(ledler[i], OUTPUT);
  }
}

void loop() {
  // Dolma: LED'ler söndürülmeden sırayla yakılır
  for (int i = 0; i < LED_SAYISI; i++) {
    digitalWrite(ledler[i], HIGH);
    Serial.print("Yanan LED sayisi: ");
    Serial.println(i + 1);
    delay(bekleme);
  }
  // Boşalma: sondan başa doğru söndürülür
  for (int i = LED_SAYISI - 1; i >= 0; i--) {
    digitalWrite(ledler[i], LOW);
    Serial.print("Yanan LED sayisi: ");
    Serial.println(i);
    delay(bekleme);
  }
}

10Uygulama 4: 4 LED ile İkili (Binary) Sayıcı

Bilgisayarlar sayıları ikili (binary) tabanda, yani yalnızca 0 ve 1 rakamlarıyla saklar. 4 LED'in her biri bir bit'i gösterirse 24 = 16 farklı durum, yani 0–15 arası sayılar gösterilebilir. En sağdaki bit en düşük değerli bittir (LSB, ağırlık 1), en soldaki bit en yüksek değerlidir (MSB, ağırlık 8).

sayı = b3·8 + b2·4 + b1·2 + b0·1    örnek: 10112 = 8 + 0 + 2 + 1 = 11
IkiliSayici.ino
// 4 LED ile 0-15 ikili sayıcı
// bit0 (LSB) -> pin 2, bit1 -> pin 3, bit2 -> pin 4, bit3 (MSB) -> pin 5
const int bitPinleri[] = {2, 3, 4, 5};

void setup() {
  Serial.begin(9600);
  for (int b = 0; b < 4; b++) {
    pinMode(bitPinleri[b], OUTPUT);
  }
}

void loop() {
  for (int sayi = 0; sayi < 16; sayi++) {      // dış döngü: sayılar
    for (int b = 0; b < 4; b++) {              // iç döngü: bitler
      // bitRead(sayi, b): sayının b. bitini 0 ya da 1 olarak verir
      digitalWrite(bitPinleri[b], bitRead(sayi, b));
    }
    Serial.print("onluk: ");
    Serial.print(sayi);
    Serial.print("  ikili: ");
    Serial.println(sayi, BIN);   // baştaki sıfırlar yazılmaz
    delay(500);
  }
}

12Kendini Test Et

1) for (int i = 0; i < 8; i++) döngüsünün gövdesi kaç kez çalışır?

✓ i = 0, 1, …, 7 değerlerini alır; i = 8 olduğunda koşul (8 < 8) yanlış olur ve döngü biter. Toplam 8 tur.

2) int ledler[] = {2, 3, 4, 5, 6, 7, 8, 9}; tanımında ledler[3] kaçtır?

✓ İndisler 0'dan başlar: ledler[0]=2, ledler[1]=3, ledler[2]=4, ledler[3]=5.

3) Kara Şimşek programında (ileri 8 + geri 6 adım) bekleme = 50 ms ise bir tam tur kaç ms sürer?

✓ 14 adım × 50 ms = 700 ms. Geri döngü uç LED'leri tekrarlamadığı için 16 değil 14 adım vardır.

4) 4 LED'li ikili sayıcıda D5, D4, D3, D2 sırasıyla ● ○ ● ● (yanık, sönük, yanık, yanık) ise gösterilen sayı kaçtır?

✓ 1011₂ = 8 + 0 + 2 + 1 = 11. D5 en yüksek değerli bit (8), D2 en düşük değerli bittir (1).

5) int i = 0; while (i < 5) { digitalWrite(13, HIGH); } kodunun sorunu nedir?

✓ Gövdede i'yi değiştiren bir komut (i++) yoktur; i hep 0 kalır, 0 < 5 hep doğrudur ve program bu satırda takılır.

13Ödev ve Özet

Ödev

  1. 8 LED ile ortadan dışa animasyon yapın: önce D5–D6, sonra D4–D7, sonra D3–D8, en son D2–D9 birlikte yansın; ardından ters sırayla içe dönsün.
  2. Kara Şimşek programını, her tam turda bekleme değeri 20 ms azalacak şekilde değiştirin; değer 20 ms'nin altına inince yeniden 200 ms'ye dönsün.
  3. 4 LED'li ikili sayıcıyı 15'ten 0'a geri sayacak şekilde düzenleyin ve her sayıyı Seri Monitör'e onluk ve onaltılık (HEX) olarak yazdırın.
  4. Yürüyen ışığı kuyruklu hâle getirin: aynı anda yan yana iki LED yansın (i ve i+1), dizi sınırı aşılmasın.
1. ödev için ipucu (tıklayın)

8 LED'lik dizide ortadaki iki indis 3 ve 4'tür. i = 0'dan 3'e kadar giden bir döngüde ledler[3 - i] ve ledler[4 + i] aynı anda yakılırsa ışık ortadan dışa yayılır.

ortadan_disa_ipucu.ino
for (int i = 0; i < 4; i++) {
  digitalWrite(ledler[3 - i], HIGH);
  digitalWrite(ledler[4 + i], HIGH);
  delay(bekleme);
  digitalWrite(ledler[3 - i], LOW);
  digitalWrite(ledler[4 + i], LOW);
}

Özet

  • for (başlangıç; koşul; artırma): başlangıç bir kez, koşul her turun başında, artırma her turun sonunda çalışır.
  • for (int i = 0; i < N; i++) kalıbı tam N tur döner; i-- ile geri, i += 2 ile atlayarak sayılır.
  • while tekrar sayısı belli olmadığında kullanılır; koşulu değiştirmeyi unutmak sonsuz döngüye yol açar.
  • Diziler pin numaralarını tek isim altında toplar; indis 0'dan başlar, son indis (eleman sayısı − 1)'dir.
  • Yürüyen ışık 8, Kara Şimşek 14, LED bar 16 adımdan oluşur; tur süresi = adım sayısı × bekleme.
  • n LED ile 2n farklı sayı gösterilir; bitRead() bir sayının istenen bitini verir.
