2Ses Dalgaları, Ultrason ve Yankı

Ses, havadaki moleküllerin sıkışıp genleşmesiyle ilerleyen mekanik bir dalgadır; boşlukta yayılamaz. İnsan kulağı yaklaşık 20 Hz – 20 kHz aralığını duyar. 20 kHz'in üzerindeki seslere ultrason denir. Yarasalar ve yunuslar ultrasonik sesler yayıp yankılarını dinleyerek çevrelerini algılar (ekolokasyon). Aynı ilke araç park sensörlerinde, robotlarda ve sıvı seviye ölçümünde kullanılır.

Ses dalgası sert bir yüzeye çarptığında bir kısmı geri yansır. Gönderme anı ile yankının geri gelme anı arasındaki süre t ölçülürse, ses hızı c bilindiğinde mesafe bulunabilir. Ses engele gidip geri döndüğü için toplam yol 2·d'dir.

Şekil 1. Verici (T) ses darbesini gönderir, engelden yansıyan yankıyı alıcı (R) yakalar. Ses yolu 2·d uzunluğundadır.

Neden 40 kHz?

  • İnsanlar duymaz; ortamı rahatsız etmez
  • Dalga boyu kısa (λ = c/f ≈ 343/40000 ≈ 8,6 mm) olduğundan küçük cisimleri de algılar
  • Piezoelektrik dönüştürücüler bu frekansta verimli çalışır

Ses hızı ve sıcaklık

Havada ses hızı sıcaklıkla artar:

c ≈ 331,3 + 0,606 · T  (m/s, T: °C)

20 °C'de c ≈ 343 m/s = 0,0343 cm/µs.

3HC-SR04 Modülünü Tanıyalım

HC-SR04, üzerinde bir verici (T) ve bir alıcı (R) piezoelektrik dönüştürücü ile bunları süren bir kontrol devresi bulunan ucuz ve yaygın bir modüldür. Arduino yalnızca ölçümü başlatır (Trig) ve yankı süresini ölçer (Echo); 40 kHz sinyal üretme ve yankıyı yükseltme işini modül kendisi yapar.

4Çalışma Prensibi ve Zamanlama Diyagramı

  1. Arduino, Trig pinine en az 10 µs süren bir HIGH darbe gönderir.
  2. Modül, verici üzerinden 8 adet 40 kHz'lik ses darbesi (yaklaşık 200 µs) yayar ve Echo pinini HIGH yapar.
  3. Ses engele çarpıp geri döner; alıcı yankıyı algıladığı anda Echo pini LOW olur.
  4. Echo pininin HIGH kaldığı süre t, sesin gidiş + dönüş süresidir. Arduino bu süreyi pulseIn() ile mikrosaniye cinsinden ölçer.
  5. Yankı hiç gelmezse modül yaklaşık 38 ms sonra Echo'yu kendiliğinden LOW yapar (zaman aşımı).
Şekil 3. HC-SR04 zamanlama diyagramı (ölçeksiz). Kırmızı kesikli çizgi zamanın akışını gösterir.
İki ölçüm arasında en az 60 ms bekleyin. Aksi hâlde bir önceki darbenin geç gelen yankısı yeni ölçümü bozabilir.

5Mesafe Hesabı

Yol = hız × zaman ve yol = 2·d olduğundan:

d = (t · c) / 2   ⟹   d [cm] = t [µs] · 0,0343 / 2 ≈ t / 58

Burada 0,0343 cm/µs, 20 °C'deki ses hızıdır (343 m/s = 34 300 cm/s = 0,0343 cm/µs). 1/(0,0343/2) ≈ 58,3 olduğundan tamsayı işlemlerde d = t / 58 yaklaşık formülü sık kullanılır.

Çözümlü Örnek

Echo pini 1166 µs HIGH kalmıştır. Engel ne kadar uzaktadır?

d = 1166 · 0,0343 / 2 = 20,0 cm   (yaklaşık formülle 1166/58 = 20 cm)

Tersinden: 1 m uzaklıktaki bir engel için t = 2·100 / 0,0343 ≈ 5831 µs ≈ 5,8 ms.

Sıcaklık değişince ses hızı değişir. Örneğin 0 °C'de c ≈ 331 m/s'dir; kodda yine 0,0343 kullanılırsa ölçülen mesafe gerçekte olduğundan yaklaşık %3,5 fazla çıkar. Hassas uygulamalarda 10. haftadaki sıcaklık sensörüyle sıcaklık düzeltmesi yapılabilir.

tone() fonksiyonu UNO'da Timer2'yi kullanır; ses çalarken D3 ve D11 pinlerinde analogWrite() (PWM) düzgün çalışmaz. Ayrıca aynı anda yalnızca tek pinde ton üretilebilir.
Aktif buzzer'lar kendi osilatörüne sahiptir; digitalWrite(pin, HIGH) ile sabit frekansta öter. Pasif buzzer ise tone() ile istenen frekansta sürülür. Aşağıdaki kod her ikisiyle de çalışır, ancak frekans ayarı yalnızca pasif buzzer'da etkilidir.

8Uygulama 1: Mesafeyi Seri Monitöre Yazdırma

mesafe_olcer.ino
// Hafta 11 – Uygulama 1: HC-SR04 ile mesafe ölçümü
const int trigPin = 9;    // Trig -> D9
const int echoPin = 10;   // Echo -> D10

void setup() {
  Serial.begin(9600);         // Seri Monitör: 9600 baud
  pinMode(trigPin, OUTPUT);   // Trig: Arduino'dan sensöre (çıkış)
  pinMode(echoPin, INPUT);    // Echo: sensörden Arduino'ya (giriş)
}

void loop() {
  // 1) Temiz bir başlangıç için Trig'i kısa süre LOW tut
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);

  // 2) 10 µs'lik HIGH darbe -> sensör 8 adet 40 kHz darbe yayar
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // 3) Echo pininin HIGH kaldığı süreyi µs cinsinden ölç
  //    (30000 µs = 30 ms zaman aşımı: yankı gelmezse 0 döner)
  unsigned long sure = pulseIn(echoPin, HIGH, 30000UL);

  if (sure == 0) {
    Serial.println("Menzil dışı / yankı yok");
  } else {
    // Ses hızı ≈ 0,0343 cm/µs; yol gidiş-dönüş olduğu için 2'ye böl
    float mesafe = sure * 0.0343 / 2.0;
    Serial.print("Süre: ");
    Serial.print(sure);
    Serial.print(" us  Mesafe: ");
    Serial.print(mesafe, 1);      // virgülden sonra 1 basamak
    Serial.println(" cm");
  }
  delay(500);   // yarım saniyede bir ölçüm
}

9Uygulama 2: LED'li ve Sesli Park Sensörü

Araçların arka tamponundaki park sensörleri engel yaklaştıkça daha sık bip sesi çıkarır. Aşağıdaki programda mesafe dört bölgeye ayrılır ve bip aralığı map() ile mesafeye bağlanır.

MesafeLED'lerBuzzer
d ≥ 100 cmhepsi sönüksessiz
50 ≤ d < 100yeşilyavaş bip (≈ 370–650 ms periyot)
20 ≤ d < 50yeşil + sarıorta hızda bip
5 ≤ d < 20yeşil + sarı + kırmızıhızlı bip
d < 5 cmhepsi yanıksürekli ses
park_sensoru.ino
// Hafta 11 – Uygulama 2: LED'li ve buzzer'lı park sensörü
const int trigPin = 9;
const int echoPin = 10;
const int yesilLed = 4;     // d < 100 cm
const int sariLed = 5;      // d < 50 cm
const int kirmiziLed = 6;   // d < 20 cm
const int buzzerPin = 8;

// Mesafeyi cm olarak ölçen yardımcı fonksiyon
long mesafeOlc() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  unsigned long sure = pulseIn(echoPin, HIGH, 30000UL);
  if (sure == 0) return 999;   // yankı yok: engel çok uzakta kabul et
  return sure / 58;            // 1 cm ≈ 58 µs (gidiş-dönüş)
}

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(yesilLed, OUTPUT);
  pinMode(sariLed, OUTPUT);
  pinMode(kirmiziLed, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  long d = mesafeOlc();
  Serial.println(d);

  // LED göstergesi: engel yaklaştıkça daha fazla LED yanar
  digitalWrite(yesilLed,   d < 100 ? HIGH : LOW);
  digitalWrite(sariLed,    d < 50  ? HIGH : LOW);
  digitalWrite(kirmiziLed, d < 20  ? HIGH : LOW);

  if (d < 5) {
    tone(buzzerPin, 2000);           // çok yakın: sürekli ses
    delay(100);
  } else if (d < 100) {
    // Mesafe küçüldükçe bip aralığı kısalır: 5 cm -> 50 ms, 100 cm -> 600 ms
    int aralik = map(d, 5, 100, 50, 600);
    tone(buzzerPin, 2000, 60);       // 60 ms'lik bip (arka planda çalar)
    delay(60 + aralik);
  } else {
    noTone(buzzerPin);               // engel uzakta: sessiz
    delay(100);
  }
}

// 5 ölçümün ortancasını (medyan) alarak ani sıçramaları bastırma
long ortancaMesafe() {
  long a[5];
  for (int i = 0; i < 5; i++) { a[i] = mesafeOlc(); delay(60); }
  // basit sıralama (insertion sort)
  for (int i = 1; i < 5; i++) {
    long k = a[i]; int j = i - 1;
    while (j >= 0 && a[j] > k) { a[j + 1] = a[j]; j--; }
    a[j + 1] = k;
  }
  return a[2];   // ortadaki eleman
}

11Kendini Test Et

Doğru seçeneği bulduğunuzda kısa bir açıklama görüntülenir.

1) Echo pini 2332 µs HIGH kalmıştır (20 °C). Engel yaklaşık ne kadar uzaktadır?

✓ d = 2332 · 0,0343 / 2 ≈ 40,0 cm (veya 2332/58 ≈ 40).

2) HC-SR04'te ölçümü başlatmak için Trig pinine ne uygulanır?

✓ Arduino yalnızca ≥10 µs tetik darbesi verir; 40 kHz'lik 8 darbeyi modülün kendisi üretir.

3) Mesafe formülünde süre neden 2'ye bölünür?

✓ Ölçülen süre gidiş + dönüş süresidir; toplam yol 2·d'dir.

4) pulseIn(echoPin, HIGH, 30000UL) hangi durumda 0 döndürür?

✓ Zaman aşımı süresi içinde darbe başlayıp bitmezse pulseIn 0 döndürür; kodda bu durum 'menzil dışı' olarak ele alınır.

5) Ortam 0 °C iken kodda 0,0343 sabiti kullanılırsa ölçülen mesafe gerçeğe göre nasıl olur?

✓ 0 °C'de ses daha yavaştır (≈331 m/s), yankı daha geç gelir; 343 m/s varsayımıyla hesaplanan mesafe ≈ %3,5 büyük çıkar.

12Ödev ve Özet

Ödev

  1. Uygulama 1'i, ölçülen mesafeyi hem cm hem inç (1 inç = 2,54 cm) olarak yazdıracak şekilde değiştirin. Ölçümü 5 farklı mesafede metreyle karşılaştırıp hata yüzdelerini bir tabloya yazın.
  2. Park sensörünü delay() kullanmadan, millis() ile bip zamanlaması yapacak biçimde yeniden yazın.
  3. Kırmızı LED'in (D6, PWM pini) parlaklığını analogWrite() ile mesafeyle ters orantılı olarak değiştirin: 100 cm'de sönük, 5 cm'de tam parlak.
  4. 10. haftadaki sıcaklık sensörünü ekleyerek ses hızını c = 331,3 + 0,606·T ile hesaplayan, sıcaklık düzeltmeli bir mesafe ölçer tasarlayın.
2. ödev için ipucu (tıklayın)
millis_bip_ipucu.ino
// İpucu: delay() yerine millis() ile bekleme yapan (bloklamayan) bip
unsigned long sonBip = 0;

void loop() {
  long d = mesafeOlc();
  // ... LED satırları aynı kalır ...
  if (d < 5) {
    tone(buzzerPin, 2000);
  } else if (d < 100) {
    unsigned long aralik = map(d, 5, 100, 50, 600) + 60;
    if (millis() - sonBip >= aralik) {   // bip zamanı geldi mi?
      tone(buzzerPin, 2000, 60);
      sonBip = millis();
    }
  } else {
    noTone(buzzerPin);
  }
  delay(60);   // HC-SR04 için ölçüm döngüsü ≥ 60 ms önerilir
}

Özet

  • HC-SR04, 40 kHz ultrasonik darbe gönderip yankısını dinleyerek 2–400 cm arası mesafe ölçer.
  • Trig'e ≥10 µs HIGH darbe verilir; Echo'nun HIGH kalma süresi pulseIn() ile µs olarak ölçülür.
  • d [cm] = t [µs] · 0,0343 / 2 ≈ t / 58; ses hızı sıcaklıkla değişir (c ≈ 331,3 + 0,606·T).
  • tone()/noTone() ile buzzer sürülür; map() ile mesafe bip aralığına dönüştürülür.
  • Ölçümler arasında ≥ 60 ms beklenmeli; yumuşak/eğik yüzeyler ve çapraz girişim hataya yol açar.
